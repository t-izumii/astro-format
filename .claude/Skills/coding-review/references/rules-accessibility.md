# アクセシビリティルール

## 基準

- 🔴 WCAG 2.2 レベルA を満たす
- 🟡 WCAG 2.2 レベルAA を目指す

## 文書構造

- 🔴 適切なランドマーク要素: `<header>`, `<nav>`, `<main>`, `<aside>`, `<footer>`
- 🔴 論理的な見出し階層（h1-h6を飛ばさない）
- 🔴 h1は1ページに1つ
- 🔴 メインコンテンツへのスキップリンクを提供
- 🔴 `<html lang="ja">`
- 🔴 各ページに固有の `<title>`

## キーボード操作

- 🔴 すべてのインタラクティブ要素をキーボードで操作可能にする
  - `<div onclick>` ❌ → `<button>` ✅
- 🔴 `tabindex` の正の値は使用禁止（`0` or `-1` のみ）
- 🔴 フォーカススタイルを削除しない（`outline: none` 単体は禁止）
- 🔴 モーダル内ではフォーカスをトラップ
- 🔴 Escキーでモーダルを閉じられるようにする
- 🟡 `:focus-visible` でキーボード操作時のみフォーカスリングを表示

## 代替テキスト

- 🔴 すべての画像に `alt` 属性
- 🔴 装飾画像は `alt=""`
- 🔴 アイコンのみのボタン: `aria-label` で説明
- 🔴 テキスト付きアイコン: SVGに `aria-hidden="true"`

## 色・コントラスト

- 🔴 通常テキスト（18px未満）: コントラスト比 4.5:1 以上（AA）
- 🔴 大きいテキスト（18px以上 or 太字14px以上）: 3:1 以上
- 🔴 UIコンポーネント・グラフィック: 3:1 以上
- 🔴 情報を色だけで伝えない（アイコンやテキストも併用）
- 🔴 リンクを色以外でも識別可能にする（下線等）

## フォーム

- 🔴 すべての入力要素に `<label>` を関連付け
- 🔴 必須項目を明示（`required` + `aria-required="true"`）
- 🔴 エラーメッセージを `aria-describedby` で関連付け、`aria-invalid="true"` を設定
- 🔴 エラーをアイコンやテキストでも示す（色のみ ❌）

## ARIA

- 🔴 セマンティックHTMLを優先、ARIAは補助的に使用
  - `<button>` ✅ / `<div role="button">` ❌（HTMLで表現できる場合）
- 🔴 フォーカス可能要素に `aria-hidden="true"` を使用しない
- 🔴 すべてのインタラクティブ要素にアクセシブルな名前を提供
- 🔴 `aria-expanded` で展開/折りたたみ状態を示す
- 🔴 `aria-current="page"` で現在のページを示す
- 🔴 `aria-live` で動的変化を通知（`polite` / `assertive`）
- 🔴 モーダルに `role="dialog"` + `aria-modal="true"` + `aria-labelledby`
- 🔴 複数 `<nav>` がある場合は `aria-label` で区別

## テキスト・アニメーション

- 🔴 最小フォントサイズ 16px 以上推奨
- 🔴 行間 `line-height: 1.5` 以上
- 🔴 `@media (prefers-reduced-motion: reduce)` でアニメーション無効化対応
- 🔴 自動再生の動画・アニメーションは5秒以内 or 停止可能
