# CSSルール

## レイヤー構造

- 🔴 詳細度の低い順から高い順へスタイルを重ねる
- 🔴 下位レイヤーのスタイルを上位レイヤーで上書きしない

| 役割 | プレフィックス | 詳細度 |
|---|---|---|
| リセット・ベース | — | 要素セレクタ |
| レイアウト | `o-` | クラスセレクタ |
| コンポーネント | `c-` | クラスセレクタ |
| ページ固有 | `p-` | クラスセレクタ |
| ユーティリティ | `u-` | クラスセレクタ |

## コードスタイル

- 🔴 インデント: スペース2つ
- 🔴 セミコロン: すべての宣言末尾に記述
- 🔴 開き括弧の前にスペース1つ
- 🔴 属性値・文字列はダブルクォート `"`
- 🔴 値0の場合は単位を省略: `margin: 0;`
- 🔴 小数点の先頭0を省略しない: `opacity: 0.5;`
- 🔴 短縮可能な16進数カラーは短縮: `#fff`
- 🔴 ベンダープレフィックスは手動で書かない（Autoprefixer使用）
- 🔴 `::before` / `::after` はダブルコロン
- 🟡 プロパティ順序: レイアウト → ボックスモデル → フォント → 背景 → その他

## 詳細度

- 🔴 詳細度を可能な限り低く保つ
- 🔴 IDセレクタをスタイリングに使用しない
- 🔴 Elements レイヤー以外で要素セレクタを単独使用しない
- 🔴 クラスセレクタと要素セレクタを結合しない: `.c-card h2` ❌ → `.c-card ._title` ✅
- 🔴 ネストは3階層まで（SCSS: `max-nesting-depth: 4`）
- 🔴 `&__` によるエレメント名の合成を禁止（クラス名が分割され検索が困難になるため）
- 🔴 `!important` はユーティリティクラスでのみ使用

```css
/* ❌ */ .c-globalNavigation a { }     /* 要素セレクタとの結合 */
/* ✅ */ .c-globalNavigation ._link { } /* クラスのみ */
```

## カスタムプロパティ

- 🔴 グローバル変数: `:root` で定義、`--` で始める、ケバブケース
- 🔴 ローカル変数: コンポーネントで定義、`--_` で始める
- 🔴 カテゴリ別命名: `--color-*`, `--spacing-*`, `--font-*`, `--z-index-*`, `--transition-*`
- 🟡 フォールバック値を指定: `var(--spacing-md, 16px)`
- 🟡 プリミティブトークンとセマンティックトークンを分ける

## レスポンシブ

- 🔴 プロジェクト内で `min-width` / `max-width` いずれかに統一（混在禁止）
- 🔴 `max-width: 100%; height: auto;` で画像を制御
- 🔴 フォントサイズには `rem` を使用
- 🔴 1次元レイアウト: Flexbox / 2次元レイアウト: Grid
- 🟡 `clamp()` で流動的なフォントサイズ
- 🟡 コンテナクエリをコンポーネント単位のレスポンシブに活用
- 🟡 `@media` は関連するセレクタの近くに記述

## ショートハンド

- 🟡 可能な限りショートハンドを使用
- 🔴 意図しない上書きを避けるため、必要な値のみ指定する場合は個別プロパティ
  - `margin-bottom: 16px;` ✅ / `margin: 0 0 16px 0;` ❌

## Sass

- 🟡 `@import` ではなく `@use` を使用
- 🔴 ネスト4階層以内
