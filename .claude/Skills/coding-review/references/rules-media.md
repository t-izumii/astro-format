# メディアリソースルール

## 画像フォーマット選定

- 🔴 写真・イラスト: WebP を第一選択（JPEG比25-35%削減）
- 🔴 ロゴ・アイコン・図形: SVG
- 🟡 アニメーション: WebP or MP4動画（GIFより推奨）
- 🟡 透過が必要な写真: WebP（フォールバック: PNG）

## 画像最適化

- 🔴 表示サイズの2倍を上限
- 🔴 ビルドプロセスで圧縮を自動化
- 🔴 ファーストビュー外の画像に `loading="lazy"`
- 🔴 `aspect-ratio` または `width`/`height` 属性でレイアウトシフト防止
- 🔴 すべての `<img>` に `alt` 属性
- 🟡 `<picture>` + `srcset` でレスポンシブ画像

### alt属性

- 🔴 意味のある画像: 内容を適切に説明
- 🔴 装飾画像: `alt=""`（空）
- 🔴 リンク内画像: リンク先を説明
- ❌ `alt="画像"`, `alt="chart.png"` のような無意味なalt

## SVG

- 🔴 すべてのSVGを最適化（SVGO等）してから使用
- 🔴 `viewBox` 属性を使用
- 🔴 CSSで色変更する場合: インラインSVG + `currentColor`
- 🔴 意味のあるSVG: `<title>` + `aria-labelledby`
- 🔴 装飾的なSVG: `aria-hidden="true"`
- 🟡 大量のアイコン: SVGスプライトを検討

## Webフォント

- 🔴 WOFF2 を使用
- 🔴 `font-display: swap` を設定
- 🔴 サブセット化（必要な文字のみ）
- 🔴 重要なフォントを `<link rel="preload">` で事前読み込み
- 🔴 適切なフォールバックフォントを指定
- 🔴 新規プロジェクトではアイコンフォントよりSVGアイコン推奨
- 🟡 複数ウェイトが必要な場合は可変フォント検討
