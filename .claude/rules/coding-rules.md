# コーディングルール

作業を始める前に、該当するフォルダの中のファイル（下の階層を含む）を読んでください。各ルールの「強さ」が必須のものは必ず守り、推奨のものも合わない事情がなければ守ってください。

- マークアップする時は `docs/guidelines/markup`、`docs/guidelines/style`、`docs/guidelines/accessibility` に記載されているルールを守ってください
- スクリプトを書く時は `docs/guidelines/script`、`docs/guidelines/accessibility` に記載されているルールを守ってください
- モーダル、アコーディオン、ドロップダウン、ハンバーガーメニュー、フォーム、カルーセル（スライダー）を作る時は、`docs/guidelines/patterns` に記載されているルールも守ってください
- どの作業でも `docs/guidelines/general` に記載されているルールを守ってください
