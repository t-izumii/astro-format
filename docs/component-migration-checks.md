## 実行した検証

- `tsc --noEmit`、`lint:js`、`lint:css`、`lint:html`、変更したファイルの Prettier チェック、`git diff --check` に合格。
- `npm run build` 成功。HTML は `index.html` と `about/index.html` のみ。ページ部品 / 開発カタログはルートに出力されず、カタログと商品カードの専用 CSS も本番に含まれない。
- ブラウザは Codex 内蔵ブラウザ。カタログの 1280px 幅で Grid は3列、390px 幅で1列・行間12px。390px 幅でページ全体の横はみ出しなし。
- Icon の既定値は16px（親の文字サイズ）。レスポンシブ指定は PC 40px / SP 24px。
- Picture の SP source が選択され、300×400px で表示されることを確認。
- 開発カタログのスライドの「次へ」で選択スライドが進むことを確認。
- 開発・本番でモーダルを開閉。本番の閉じるボタン・Escape で閉じ、起点へフォーカスが戻ることを確認。
- 本番の About へ直接アクセス・再読み込みが成功。単一化された script.js のモーダル動作を確認し、本番確認時のブラウザエラーはなし。

初回の開発ブラウザで Astro 開発ツールバーの動的 import エラーを1件観測した。アプリの初期化・操作は成立し、本番では発生していない。開発ツールバー自体は今回の変更対象外。

Safari / Firefox、スクリーンリーダーの実読み上げ、既存の全アニメーション状態は未検証。今回変更していない実行基盤や外部画像サービスの全挙動を保証するものではない。
