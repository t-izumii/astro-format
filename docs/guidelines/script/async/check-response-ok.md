# fetch の結果は response.ok を確かめてから使う

- 強さ: 必須
- 対象: `fetch()` で通信する処理。

`fetch()` の結果を使う前に `response.ok` を確かめ、`false` なら失敗として扱う。

理由: `fetch()` は、通信できない場合などには失敗するが、サーバーが 404 や 500 を返した場合は成功として結果を返す。確かめずに本文を読むと、エラーのページを正常なデータとして扱い、表示が壊れる。

例外・代替: なし。

- 構築: 通信の処理は、状態の確認と失敗の扱いを含めて1か所にまとめ、呼び出す側で毎回書かせない。
- レビュー: `fetch(` を検索し、`ok` か `status` を確かめているかを確認する。
