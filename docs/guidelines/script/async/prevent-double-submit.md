# 処理中は同じ操作を受け付けない

- 強さ: 必須
- 対象: 送信、購入、登録など、二重に実行されると困る処理。

処理中であることを変数で持ち、処理中に同じ操作が来たら実行しない。ボタンの見た目も処理中に切り替える。

理由: 通信を待っている間にもう一度押すと、同じ注文や問い合わせが二重に送られる。見た目だけを無効にしても、Enter での送信などの経路から実行されることがある。

例外・代替: ボタンに `disabled` を付けて止める方法も使える。ただし `disabled` の要素はフォーカスを受け取れなくなるので、押したボタンにあったフォーカスがどうなるかを確認する。フォーカスを残したい場合は、`aria-disabled="true"` と処理中の変数で止める。

- 構築: 処理が成功しても失敗しても、処理中の状態を必ず解除する（`finally` で解除する）。
- レビュー: 送信ボタンを素早く2回押す、Enter を連打する、の両方で、処理が1回だけ実行されるかを確かめる。
