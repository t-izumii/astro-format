# 失敗したら、起きたことと次にできることを示す

- 強さ: 必須
- 対象: 失敗すると利用者が目的を達成できない処理。

失敗の表示には、何がうまくいかなかったかと、利用者が次にできること（もう一度試す、時間をおく、問い合わせる）を書く。もう一度試せる処理には、やり直しのボタンを置く。

理由: 「エラーが発生しました」だけでは、利用者は待てばよいのか、入力を直すべきか、あきらめるべきかが分からない。

例外・代替: サーバーから返ったエラーの内容や技術的な詳細は、そのまま表示しない。必要な情報は開発者向けの記録に残す。

- 構築: やり直しのボタンを押したときに、入力した内容や選んだ条件が引き継がれるようにする。
- レビュー: 失敗の表示に、次にできることが書かれているかを確認する。
