# 非同期処理には、処理中・成功・空・失敗の表示をすべて用意する

- 強さ: 必須
- 対象: 通信など、結果を待つ処理の結果を画面に表示する場合。

成功したときの表示だけでなく、処理中、結果が0件、失敗のそれぞれで何を表示するかを決めて実装する。

理由: 成功の表示しかないと、処理中は何も起きていないように見え、0件や失敗のときは画面が空のまま止まる。利用者は待つべきか、やり直すべきかを判断できない。

例外・代替: すぐに終わる処理で、処理中の表示が一瞬だけちらつく場合は、一定時間を過ぎてから処理中の表示を出してよい。

- 構築: 表示の状態を「処理中・成功・空・失敗」の4つで設計し、どの状態からどの状態へ移るかを決める。
- レビュー: 通信を遅くする、0件になる条件で検索する、通信を切る、の3つを試し、それぞれの表示を確かめる。
