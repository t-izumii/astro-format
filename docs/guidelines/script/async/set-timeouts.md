# 待ち時間の上限を決める

- 強さ: 推奨
- 対象: 応答が返らないと利用者が先へ進めない処理。

待ち時間の上限を決め、超えたら失敗として扱う。`AbortSignal.timeout()` を使うと、時間切れは `TimeoutError` になり、利用者による中断（`AbortError`）と区別できる。

理由: 上限を決めないと、応答が返らないときに処理中の表示が終わらず、利用者はいつまで待てばよいか分からない。

例外・代替: `AbortSignal.timeout()` は MDN で Baseline 2024 とされている。対象のブラウザが古い版を含む場合は、`AbortController` と `setTimeout()` で同じ動きを作る。

- 構築: 上限の時間は処理の内容から決め、ファイルのアップロードのように長くかかる処理には長めの上限を設ける。
- レビュー: 応答を返さない状態を作り、上限の時間で失敗の表示に切り替わるかを確かめる。
