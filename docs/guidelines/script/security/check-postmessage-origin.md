# postMessage は、送り先と送り元のオリジンを確かめる

- 強さ: 必須
- 対象: `postMessage` で他のウィンドウや `iframe` とやり取りする場合。

送るときは、送り先のオリジンを `*` ではなく正確に指定する。受け取るときは、`event.origin` が想定するオリジンと完全に一致するかを確かめ、一致しなければ何もしない。受け取ったデータの形も確かめる。

理由: 送り先を `*` にすると、別のサイトに書き換えられたウィンドウにデータが届く。送り元を確かめないと、どのサイトからでも処理を動かせる。`includes()` などの部分一致で確かめると、`example.com.attacker.test` のようなオリジンを通してしまう。

例外・代替: なし。

- 構築: 許可するオリジンは定数で持ち、`===` で比較する。
- レビュー: `postMessage` と `message` のイベントを検索し、オリジンの指定と確認があるかを確認する。
