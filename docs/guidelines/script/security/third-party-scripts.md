# 外部のスクリプトは、必要なものだけを、改ざんを検知できる形で読み込む

- 強さ: 推奨
- 対象: CDN など、自サイト以外から `script` を読み込む場合。

外部のスクリプトは、版を固定して読み込み、`integrity` 属性でファイルのハッシュを指定する。使っていない外部のスクリプトは削除する。

理由: 外部のスクリプトは、ページと同じ権限で動く。配信元のファイルが改ざんされると、`integrity` を指定していないページでは、そのまま実行される。

例外・代替: アクセス解析のタグなど、配信元が内容を更新し続けるスクリプトは `integrity` を指定できない。読み込む数を必要なものに絞る。

- 構築: `integrity` を指定するときは、`crossorigin="anonymous"` も合わせて付ける。
- レビュー: 外部から読み込む `script` に、版の固定と `integrity` があるかを確認する。
