# 外部から来た URL は、スキームを確かめてから属性に入れる

- 強さ: 必須
- 対象: 利用者の入力や API から取得した URL を、`href` や `src` に入れる場合。

URL を `new URL()` で解析し、スキームが `https:`（必要なら `http:`）であることを確かめてから入れる。

理由: `javascript:` で始まる URL をリンクに入れると、クリックしたときに任意のコードが実行される。

例外・代替: サイト内の相対パスだけを許す場合は、解析した結果のオリジンが自サイトと一致するかを確かめる。

- 構築: 許可するスキームを一覧で持ち、一覧にないものは使わない。禁止するスキームを列挙する方法は、漏れが出るので使わない。
- レビュー: 外部から来た値を `href`・`src`・`location` に入れている箇所で、スキームを確かめているかを確認する。
