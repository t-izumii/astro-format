# 認証の情報を localStorage に保存しない

- 強さ: 必須
- 対象: ログインの状態や、API の認証に使うトークンを扱う場合。

セッションの識別子や認証のトークンを `localStorage` や `sessionStorage` に保存しない。サーバー側で、スクリプトから読めない Cookie（`HttpOnly`）に保存する。

理由: `localStorage` の値は、そのページで動くすべてのスクリプトから読める。一つでもスクリプトを挿入できる欠陥があると、保存したすべての値が盗まれる。

例外・代替: 認証の方式が外部のサービスで決まっている場合は、そのサービスの推奨する保存方法に従う。

- 構築: `localStorage` には、表示の設定など、漏れても困らない値だけを保存する。
- レビュー: `localStorage.setItem` を検索し、認証の情報や個人情報を保存していないかを確認する。
