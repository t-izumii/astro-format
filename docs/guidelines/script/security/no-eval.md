# 文字列をコードとして実行しない

- 強さ: 必須
- 対象: すべてのスクリプト。

`eval()`、`new Function()`、文字列を渡す `setTimeout()`・`setInterval()` を使わない。

理由: 文字列が外部の影響を受けると、その文字列がページの権限でコードとして実行される。厳しいコンテンツセキュリティポリシー（CSP）を設定した案件では、これらは動かない。

例外・代替: なし。

- 構築: 処理を後で実行したい場合は、関数を渡す。
- レビュー: `eval(`、`new Function(`、文字列を渡す `setTimeout(` を検索する。
