# 秘密情報をフロントエンドのコードに置かない

- 強さ: 必須
- 対象: API キー、パスワード、署名用の鍵などを扱う場合。

秘密にすべき鍵やパスワードを、スクリプト、HTML、ビルド時に埋め込む環境変数に書かない。秘密の鍵が必要な処理は、サーバー側で行う。

理由: ブラウザに届いたコードは、誰でも読める。ビルド時に埋め込んだ環境変数も、出力されたファイルにそのまま含まれる。

例外・代替: 公開を前提に発行され、利用できるドメインなどを制限できるキー（地図サービスのブラウザ用キーなど）は置いてよい。その場合も、提供元の画面で利用の制限を設定する。

- 構築: 環境変数をフロントエンドで使う前に、その値が公開されてよいものかを確認する。
- レビュー: ビルドしたファイルを検索し、秘密の鍵が含まれていないかを確認する。
