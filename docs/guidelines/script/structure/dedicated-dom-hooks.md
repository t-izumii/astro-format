# DOM を取得する目印に、見た目用のクラスを使わない

- 強さ: 必須
- 対象: スクリプトで要素を取得する場合。

スクリプトから要素を取得するときは、スクリプトのための目印（専用の属性やクラス）を使う。見た目のために付けたクラスを目印に流用しない。どの目印を使うかは案件で決める。

理由: 見た目のクラスを目印にすると、デザインの変更でクラス名を変えたり消したりしたときに、スクリプトが黙って動かなくなる。逆に、スクリプトが使っているとは知らずに、使われていないように見えるクラスを消してしまうこともある。

例外・代替: 状態を表す ARIA の属性（`aria-expanded` など）は、目印として取得してよい。

- 構築: 目印は、それを使うスクリプトが分かる名前にする。
- レビュー: `querySelector` などに渡しているセレクタが、見た目用のクラスでないかを確認する。
