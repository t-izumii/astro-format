# 部品を取り除くときは、登録したイベントとタイマーを解除する

- 強さ: 必須
- 対象: 画面の書き換えなどで、表示中に追加・削除される部品。

部品を取り除くときは、その部品が登録したイベント、タイマー、監視（`IntersectionObserver` など）をすべて解除する。イベントは、登録時に `AbortController` の `signal` を渡しておくと、`abort()` の1回でまとめて解除できる。

理由: 解除しないと、取り除いた部品の処理が動き続け、存在しない要素を操作してエラーになったり、メモリを使い続けたりする。`window` や `document` に登録したイベントは、部品を消しても残る。

例外・代替: ページの読み込みから離脱まで存在し続ける部品は、解除しなくてよい。

- 構築: 初期化の関数が、後片付けの関数を返すようにする。
- レビュー: 部品を取り除いたあとに、その部品のイベントやタイマーが動いていないかを確かめる。
