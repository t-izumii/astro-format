# スクロールや大きさの変化は、監視の仕組みで受け取る

- 強さ: 推奨
- 対象: 要素が画面に入ったときの演出や、要素の大きさに合わせた処理。

要素が画面に入ったかどうかは `IntersectionObserver`、要素の大きさの変化は `ResizeObserver` で受け取る。`scroll` や `resize` のイベントを使う場合は、`passive: true` を指定し、イベントのたびに要素の位置や大きさを読み取る処理をしない。

理由: `scroll` のイベントは短い間隔で何度も発生し、そのたびに位置を計算するとスクロールが引っかかる。`passive: true` を指定すると、ブラウザは処理の終わりを待たずにスクロールできる。

例外・代替: スクロールの量そのものを使う演出は、`scroll` のイベントを使ってよい。その場合も、画面の更新に合わせて処理の回数を絞る。

- 構築: 演出が終わった要素は、監視から外す。
- レビュー: `scroll` と `resize` のイベントを検索し、監視の仕組みで置き換えられないかを確認する。
