# 同じ要素を二度初期化しない

- 強さ: 推奨
- 対象: 初期化の処理が複数回呼ばれうる場合（部分的な再読み込み、CMS のプレビュー、画面の書き換えなど）。

初期化した要素を記録し、同じ要素への二度目の初期化を行わない。

理由: 二度初期化すると、同じイベントが二重に登録され、1回のクリックで開閉が2回起きて元に戻る、送信が2回行われる、といった不具合になる。

例外・代替: 初期化が何度呼ばれても結果が変わらない作りになっている場合は不要。

- 構築: 初期化済みの要素は `WeakSet` などで覚えておく。
- レビュー: 初期化の処理を2回呼んだときに、動作が二重にならないかを確かめる。
