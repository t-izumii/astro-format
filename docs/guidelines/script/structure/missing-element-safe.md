# 対象の要素がないページでも、エラーにならないようにする

- 強さ: 必須
- 対象: 複数のページで共通に読み込むスクリプト。

要素を取得したら、存在するかを確かめてから処理する。要素がなければ、その処理だけを何もせずに終える。

理由: 共通のスクリプトは、対象の部品がないページでも読み込まれる。`null` に対して処理をするとエラーで止まり、同じファイルの後ろにある無関係な処理まで動かなくなる。

例外・代替: 必ず存在するはずの要素がない場合は、黙って終えずに、開発中に気づけるようにエラーを出してよい。

- 構築: 部品ごとの初期化の関数は、対象の要素が見つかった場合だけ呼ぶ。
- レビュー: 部品のないページでスクリプトのエラーが出ていないかを、ブラウザのコンソールで確かめる。
