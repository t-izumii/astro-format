# スクリプトは defer か type="module" で読み込む

- 強さ: 推奨
- 対象: `script` 要素でスクリプトを読み込む場合。

`head` に置く `script` には `defer` を付けるか、`type="module"` にする。他のスクリプトとの実行順を問わないもの（アクセス解析など）は `async` でよい。

理由: どちらも付けない `script` は、読み込みと実行が終わるまで HTML の解析を止め、ページの表示が遅れる。`defer` と `type="module"` は解析のあとに、書いた順番で実行される。`async` は読み込めた順に実行されるので、順番が必要な処理には使わない。

例外・代替: ページの表示前に実行する必要がある短い処理（テーマの切り替えでちらつきを防ぐ処理など）は、`head` で直接実行してよい。

- 構築: `type="module"` のスクリプトに `defer` を重ねて書かない。最初から遅れて実行される。
- レビュー: `defer`・`async`・`type="module"` のない `script` が `head` にないかを確認する。
