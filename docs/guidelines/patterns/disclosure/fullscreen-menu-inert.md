# 画面全体を覆うメニューでは、背景にフォーカスが移らないようにする

- 強さ: 必須
- 対象: 開くとページ全体を覆うハンバーガーメニューなど、背景の内容を操作できない見た目になる開閉部品。
- WCAG: 2.4.3 A

画面全体を覆うメニューは、モーダルのダイアログとして作るか、開いている間は背景の内容に `inert` を付ける。閉じたら、開いたボタンへフォーカスを戻す。

理由: 見た目は背景を覆っていても、背景の内容が操作できる状態のままだと、Tab で覆われた背景の中へフォーカスが移り、利用者からは見えなくなる。

例外・代替: メニューが画面の一部だけを覆い、背景も見えて操作できる作りなら、通常の開閉部品として扱う。

- 構築: 開閉のボタンを背景側に置いたまま背景に `inert` を付けると、ボタン自体も操作できなくなる。閉じるボタンはメニューの中にも置く。
- レビュー: メニューを開いた状態で Tab を押し続け、フォーカスが背景へ移らないかを確かめる。
