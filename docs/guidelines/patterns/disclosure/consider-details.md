# 単純な開閉は details と summary で足りるかを先に検討する

- 強さ: 推奨
- 対象: よくある質問、補足の表示など、内容を見せる・隠すだけの開閉。

`details` と `summary` は、スクリプトなしで開閉・キー操作・状態の伝達がそろう。同じ `name` 属性を付けた `details` は、1つを開くと他が閉じる。次の場合は、`button` と `aria-expanded` で作る。

- 題名を見出しとして伝える必要がある。
- 開閉にアニメーションが必要。`details` には開閉を滑らかに動かす標準の方法がない。
- 開いた状態を他の部品と連動させる必要がある。

理由: 標準の要素で足りるなら、スクリプトでの状態の管理と、その更新漏れが生じない。

例外・代替: `name` 属性による排他的な開閉は Chrome 120、Firefox 130、Safari 17.2 以降で動く。それより古いブラウザでは、複数の項目が同時に開くだけで、内容は読める。

- 構築: 対象のブラウザで `name` 属性が使えない場合に、同時に開いても困らないかを確認する。
- レビュー: スクリプトで開閉している部品のうち、`details` で置き換えられるものがないかを確認する。
