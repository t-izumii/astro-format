# アコーディオンの見出しは、見出し要素の中にボタンを置く

- 強さ: 必須
- 対象: 開閉する各項目の題名が、ページの見出しとしての役割も持つ場合。
- WCAG: 1.3.1 A

見出し要素の中にボタンを置き、見出しの中にはボタン以外を入れない。ボタンの中に見出し要素を入れない。

理由: 見出しの中にボタンを置けば、見出しの一覧から項目へ移動でき、ボタンとしても操作できる。ボタンの中に見出し要素を入れることは HTML の仕様で認められておらず、見出しとして伝わらない。

例外・代替: 題名が見出しの役割を持たない短い開閉（「続きを読む」など）は、ボタンだけでよい。

- 構築: 見出しのレベルは、ページの見出しの階層に合わせる。
- レビュー: `button` の中に `h2`〜`h6` がないか、見出しの中にボタン以外の要素がないかを確認する。

## サンプル: 見出しとボタンの入れ子

```html
<!-- 問題例: ボタンの中に見出しを入れている -->
<button type="button" aria-expanded="false"><h3>送料について</h3></button>

<!-- 改善例 -->
<h3>
  <button type="button" aria-expanded="false" aria-controls="faq-shipping">
    送料について
  </button>
</h3>
```
