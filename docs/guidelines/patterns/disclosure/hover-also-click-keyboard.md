# ホバーで開く場合も、クリックとキーボードで開閉できるようにする

- 強さ: 必須
- 対象: ホバーで子の一覧や補足を開く部品。
- WCAG: 2.1.1 A

ホバーで開く作りにする場合も、開閉のボタンを置き、クリック・タップ・キーボードで開閉できるようにする。ホバーで開いた内容の条件は、[キーボードとフォーカス](../../accessibility/keyboard-focus/)の「[ホバーで現れる内容はフォーカスでも表示し、Esc で閉じられるようにする](../../accessibility/keyboard-focus/hover-content.md)」に従う。

理由: タッチ端末にはホバーがなく、キーボードの利用者もホバーを使えない。ホバーだけで開く部品は、これらの利用者には開けない。

例外・代替: なし。

- 構築: ポインターがボタンから開いた内容へ移る間に閉じないよう、閉じるまでに短い猶予を置くか、両者の間に隙間を作らない。
- レビュー: タッチ端末のエミュレーションと Tab で、ホバーを使わずに開閉できるかを確かめる。
