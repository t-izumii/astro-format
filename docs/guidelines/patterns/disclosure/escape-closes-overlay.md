# 重なって表示する開閉部品は、Esc で閉じてボタンへフォーカスを戻す

- 強さ: 推奨
- 対象: ドロップダウンのように、ページの他の内容の上に重なって開く部品。

開いている間に Esc を押したら閉じ、開いたボタンへフォーカスを戻す。アコーディオンのように、ページの流れの中で開く部品には必要ない。

理由: 重なった内容は下の内容を隠すため、すぐに閉じる手段があると操作の手間が減る。フォーカスを戻せば、利用者は開く前の位置から操作を続けられる。

例外・代替: なし。

- 構築: 内容の中にフォーカスがあるときに Esc を押しても閉じられるよう、キーの処理は部品全体で受け取る。
- レビュー: 開いた内容の中のリンクにフォーカスした状態で Esc を押し、閉じてボタンへ戻るかを確かめる。
