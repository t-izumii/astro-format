# ダイアログには見える題名を置き、それで名前を付ける

- 強さ: 必須
- 対象: すべてのダイアログ。
- WCAG: 4.1.2 A

ダイアログの先頭に見出しで題名を置き、`aria-labelledby` でその見出しを指す。

理由: 名前のないダイアログは、開いたときに何のダイアログかが支援技術の利用者に伝わらない。

例外・代替: 見える題名を置けない場合は、`aria-label` で名前を付ける。

- 構築: 題名は、ダイアログで何をするかが分かる文にする（「確認」ではなく「この記事を削除しますか」）。
- レビュー: ダイアログを開いたときに、題名が名前として伝わるかを開発者ツールで確かめる。
