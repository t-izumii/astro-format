# 利用者の応答が必要ないものをモーダルにしない

- 強さ: 推奨
- 対象: 通知、案内、Cookie の同意など、ページに重ねて表示する内容。

モーダルは、利用者が応答するまで先へ進めない場面だけに使う。保存の完了通知や補足の案内は、ページの中に表示するか、非モーダルにする。

理由: モーダルはそれまでの作業を中断させ、閉じるまで他の操作をできなくする。必要のない場面で使うと、利用者は毎回閉じる操作を強いられる。

例外・代替: 法的な同意など、応答を得るまで先へ進めない理由がある場合はモーダルにしてよい。

- 構築: ダイアログを作る前に、閉じるまで他の操作を止める必要があるかを確認する。
- レビュー: モーダルで表示している内容が、応答を必要としているかを確認する。
