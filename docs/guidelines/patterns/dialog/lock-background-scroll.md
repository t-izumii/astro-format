# 開いている間は、背景のページをスクロールさせない

- 強さ: 推奨
- 対象: モーダルのダイアログ。

モーダルを開いている間は、ページ全体のスクロールを止める。`:modal` 疑似クラスと `:has()` を使えば、スクリプトで状態を管理せずに書ける。

理由: 背景を操作できない状態でも、ホイールやタッチでページがスクロールすることがある。閉じたあとに元の位置からずれていると、利用者が読んでいた場所を見失う。

例外・代替: スクロールバーが消えてページの横幅が変わる場合は、その幅を補う。

- 構築: ダイアログの中身が長い場合は、ダイアログ自体をスクロールできるようにする。
- レビュー: ダイアログを開いた状態で背景の上をスクロールし、ページが動かないかを確かめる。

```css
html:has(dialog:modal) {
  overflow: hidden;
}
```
