# 閉じたら、開いたボタンへフォーカスを戻す

- 強さ: 必須
- 対象: すべてのダイアログ。
- WCAG: 2.4.3 A

閉じたときは、ダイアログを開いたボタンへフォーカスを戻す。Esc、閉じるボタン、背景のクリックなど、どの方法で閉じても戻るように、`close` イベントで処理する。

理由: フォーカスが戻らないと、利用者はページの先頭から移動し直すことになる。閉じるボタンの処理だけで戻すと、Esc で閉じたときに戻らない。

例外・代替: 開いたボタンが閉じた時点で存在しない場合（削除した項目のボタンなど）は、続きの操作がしやすい場所へ移す。

- 構築: ダイアログを開く前に、開いた要素を覚えておく。
- レビュー: Esc、閉じるボタン、背景のクリックのそれぞれで閉じ、フォーカスが開いたボタンへ戻るかを確かめる。
