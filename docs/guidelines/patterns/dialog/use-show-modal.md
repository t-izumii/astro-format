# モーダルは dialog 要素と showModal() で開く

- 強さ: 必須
- 対象: 開いている間、ページの他の部分を操作させないダイアログ。
- WCAG: 2.4.3 A

モーダルのダイアログは `<dialog>` 要素を `showModal()` で開く。`open` 属性の付け外しや `show()` で開かない。`div` に `role="dialog"` を付けて、フォーカスの閉じ込めや背景の無効化を自作しない。`<dialog>` 要素に `tabindex` を付けない。

理由: `showModal()` で開くと、ブラウザがダイアログの外を操作できない状態（inert）にし、Esc で閉じられるようにし、ダイアログの中へフォーカスを移す。`open` 属性や `show()` で開いたダイアログはモーダルにならず、背景にフォーカスが移る。自作すると、これらの一つでも漏れたときに操作できなくなる。

例外・代替: 背景も操作できてよいダイアログ（開いたまま作業を続けるパネルなど）は、`show()` で非モーダルとして開く。

- 構築: 開く処理は `showModal()`、閉じる処理は `close()` に統一する。
- レビュー: ダイアログを開いた状態で Tab を押し続け、フォーカスが背景へ移らないか、Esc で閉じるかを確かめる。
