# 開いたときの最初のフォーカス先を決める

- 強さ: 必須
- 対象: すべてのダイアログ。
- WCAG: 2.4.3 A

何も指定しなければ、ブラウザはダイアログの中で最初にフォーカスできる要素へフォーカスを移す。それが適切でない場合は、`autofocus` 属性で最初のフォーカス先を指定する。

| ダイアログの内容 | 最初のフォーカス先 |
|---|---|
| 削除など、取り消せない操作の確認 | 影響の小さい操作（キャンセル） |
| 長い文章や規約など、先頭から読む内容 | 先頭の題名（`tabindex="-1"` を付ける） |
| 入力フォーム | 最初の入力欄 |

理由: 先頭の要素が「削除する」ボタンだと、Enter を押しただけで取り消せない操作が実行される。長い内容の途中にある要素へフォーカスすると、先頭が画面外へスクロールして読めなくなる。

例外・代替: なし。

- 構築: 確認ダイアログでは、ボタンの並び順に関係なく、キャンセルに `autofocus` を付ける。
- レビュー: 開いた直後にフォーカスがどこにあるか、その位置で Enter を押したときに何が起きるかを確かめる。
