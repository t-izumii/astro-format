# 入力の途中でエラーを出さない

- 強さ: 推奨
- 対象: 入力内容をその場で検証するフォーム。

検証は、利用者が欄から移ったときか、送信したときに行う。一度エラーを出した欄は、入力のたびに再検証し、直ったらすぐにエラーを消す。

理由: 1文字目からエラーを出すと、まだ入力中の利用者を責めることになり、読み上げも繰り返される。

例外・代替: パスワードの条件を満たしたかを入力中に示すなど、エラーではなく達成状況を伝える表示は、入力中に更新してよい。

- 構築: 欄ごとに「エラーを出したことがあるか」を覚えておき、再検証の頻度を切り替える。
- レビュー: 入力を始めた直後にエラーが出ないかを確かめる。
