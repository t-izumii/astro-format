# フォームの中のボタンには type を書く

- 強さ: 必須
- 対象: `form` の中に置くすべての `button`。

`button` には必ず `type` を書く。送信するボタンは `type="submit"`、それ以外（パスワードの表示切り替え、入力欄の追加など）は `type="button"` にする。

理由: `type` を省いた `button` は送信ボタンとして扱われ、補助の操作のつもりで押したボタンでフォームが送信される。

例外・代替: なし。

- 構築: フォームの外のボタンにも `type` を書く習慣にしておくと、後からフォームの中へ移したときに困らない。
- レビュー: `form` の中の `button` に `type` があるかを確認する。
