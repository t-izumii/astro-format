# 関連する入力欄のまとまりは fieldset と legend で囲む

- 強さ: 必須
- 対象: ラジオボタンやチェックボックスの選択肢、電話番号や生年月日のように複数の欄で1つの値を入力する箇所。
- WCAG: 1.3.1 A、3.3.2 A

まとまりを `fieldset` で囲み、`legend` に質問や項目名を書く。

理由: 「はい」「いいえ」のような選択肢のラベルだけでは、何に対する答えか分からない。`legend` があれば、選択肢に移ったときに質問も伝わる。

例外・代替: なし。

- 構築: `legend` の見た目は CSS で調整できるので、見た目のために `div` と見出しで代用しない。
- レビュー: 選択肢のまとまりに `fieldset` と `legend` があるかを確認する。
