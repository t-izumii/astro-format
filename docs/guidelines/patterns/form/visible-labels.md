# 入力欄には見えるラベルを付け、placeholder をラベルの代わりにしない

- 強さ: 必須
- 対象: すべての入力欄。
- WCAG: 3.3.2 A

入力欄ごとに `label` 要素で見えるラベルを付け、`for` と `id` で結び付ける。`placeholder` は入力例を示すためだけに使う。

理由: `placeholder` は入力を始めると消え、何を入れる欄だったか分からなくなる。文字のコントラストも低く、スクリーンリーダーで読まれないことがある。

例外・代替: 検索欄のように、隣のボタンなどで目的が明らかな欄は、ラベルを画面に表示しない文字にしてよい。

- 構築: デザインにラベルがない場合も、ラベルを省かずにデザインの担当者へ確認する。
- レビュー: `placeholder` だけで目的を示している入力欄がないかを確認する。
