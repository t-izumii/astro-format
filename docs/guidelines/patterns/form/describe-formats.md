# 形式の説明は aria-describedby で入力欄に結び付ける

- 強さ: 必須
- 対象: 「半角数字」「8文字以上」など、入力の形式に条件がある欄。
- WCAG: 1.3.1 A

形式の説明はラベルの近くに見える文字で書き、`aria-describedby` で入力欄に結び付ける。入力欄に入ってから気づくことのないよう、説明は入力欄より前か、すぐそばに置く。

理由: 結び付けていない説明は、入力欄へ移ったときに読み上げられず、支援技術の利用者は条件を知らないまま入力する。

例外・代替: なし。

- 構築: エラーの文と説明の両方がある場合は、`aria-describedby` に両方の `id` を空白区切りで書く。
- レビュー: 形式に条件がある欄で、説明が名前や説明として伝わるかを開発者ツールで確かめる。
