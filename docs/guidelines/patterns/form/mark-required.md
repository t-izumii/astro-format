# 必須の項目は文字で示し、required 属性を付ける

- 強さ: 必須
- 対象: 入力が必須の欄。
- WCAG: 3.3.2 A

ラベルの中に「必須」と文字で書き、入力欄に `required` 属性を付ける。色や記号（※、*）だけで示さない。独自の検証を使う場合は、`form` に `novalidate` を付けてブラウザの検証表示を止め、`required` は残す。

理由: 色や記号だけでは、色の区別が難しい利用者や支援技術の利用者に必須であることが伝わらない。`required` があれば、必須であることが支援技術にも伝わる。

例外・代替: ほぼすべての項目が必須のフォームでは、「任意」の項目に文字で示す方法でもよい。どちらの方式かをフォームの冒頭に書く。

- 構築: 記号を使う場合は、その意味をフォームの冒頭に文字で書く。
- レビュー: 必須の欄すべてに、文字の表示と `required` 属性の両方があるかを確認する。
