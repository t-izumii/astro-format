# 自動で切り替わるカルーセルには、止めるボタンを付ける

- 強さ: 必須
- 対象: スライドが自動で切り替わるカルーセル。
- WCAG: 2.2.2 A

自動で切り替わるカルーセルには、切り替えを止めるボタンと再開するボタンを付ける。ボタンは `button` 要素で作り、カルーセルの中で最初にフォーカスが当たる位置に置く。カルーセルの中にフォーカスがある間と、ポインターが乗っている間は、切り替えを止める。

理由: 読み終わる前にスライドが切り替わると、読む速さが遅い利用者は内容を読めない。操作しようとしたリンクが切り替えで入れ替わると、意図しないリンクを開いてしまう。動き続ける内容は、ほかの内容に集中するのも妨げる。

例外・代替: 自動で切り替えないカルーセルには要らない。自動で切り替える必要があるかを、先にデザインの段階で確かめる。

- 構築: ボタンの名前は、「スライドの自動切り替えを停止」「スライドの自動切り替えを再開」のように、押すと起きることに合わせて切り替える。フォーカスやホバーで止めるだけでは足りない。ボタンで止めたあとは、フォーカスやポインターが外れても再開しない。動きを抑える設定のときは、自動で切り替えない（[動きを抑える設定のときは、動きを伴うアニメーションを止めるか控えめにする](../../accessibility/perception/reduce-motion.md)）。
- レビュー: 止めるボタンが見える場所にあり、キーボードで操作できるかを確かめる。止めたあとに、切り替えが再開しないかも確かめる。

## サンプル

```html
<button type="button" class="carousel-pause" data-carousel-pause>
  <svg aria-hidden="true">…</svg>
  <span class="visually-hidden">スライドの自動切り替えを停止</span>
</button>
```
