# カルーセルの前後のボタンと、スライドを選ぶボタンに名前を付ける

- 強さ: 必須
- 対象: カルーセルの前へ・次へのボタンと、スライドを選ぶ点やサムネイルのボタン。
- WCAG: 4.1.2 A

前へ・次へと、スライドを選ぶ点は、`button` 要素で作る。矢印や点だけのボタンには、「前のスライド」「次のスライド」「スライド2を表示」のように名前を付ける。スライドを選ぶボタンでは、表示中のスライドに当たるものに `aria-current="true"` を付ける。

理由: 矢印のアイコンや点だけのボタンは、名前がないと、スクリーンリーダーで「ボタン」としか読まれない。`div` や `span` で作った点は、キーボードで操作できない。どのスライドが表示中かは、点の色だけでは伝わらない。

例外・代替: 端のスライドで前へ・次へを押せなくする場合は、ボタンを消さずに `disabled` を付ける。

- 構築: ライブラリが出力するボタンは、要素の種類と名前を確かめる。名前が英語の既定値のままなら、日本語に直す。同じページにカルーセルが複数ある場合は、「お知らせの次のスライド」のように、どのカルーセルのボタンかが分かる名前にする。
- レビュー: 前後のボタンとスライドを選ぶボタンの名前を、開発者ツールのアクセシビリティ表示で確認する。Tab で到達でき、Enter と Space で動くかも確かめる。

## サンプル

```html
<button type="button" aria-label="前のスライド">
  <svg aria-hidden="true">…</svg>
</button>
<button type="button" aria-label="次のスライド">
  <svg aria-hidden="true">…</svg>
</button>

<ul class="carousel-dots">
  <li><button type="button" aria-label="スライド1を表示" aria-current="true"></button></li>
  <li><button type="button" aria-label="スライド2を表示"></button></li>
</ul>
```
