# 見えていないスライドの中に、フォーカスを入れない

- 強さ: 必須
- 対象: 表示中でないスライドの中に、リンクやボタンなどの操作要素があるカルーセル。
- WCAG: 2.4.3 A

表示中でないスライドには `inert` 属性を付け、表示されたら外す。ループのために複製したスライドにも付ける。

理由: 多くのカルーセルは、表示中でないスライドを画面の外へずらしているだけで、中のリンクには Tab で到達できる。フォーカスが見えない場所へ移り、利用者は今どこにいるかを見失う。複製したスライドがあると、同じリンクが何度も読み上げられる。

例外・代替: スライドの中に操作要素がなく、表示中でないスライドを `visibility: hidden` などで隠している場合は、`inert` は要らない。複数のスライドを同時に見せるカルーセルでは、一部でも見えているスライドには付けない。

- 構築: 切り替えが終わった時点で、`inert` を付け替える。ライブラリの設定で対応できる場合はそれを使い、できない場合は切り替えのイベントで付け替える。
- レビュー: カルーセルの中を Tab で進み、見えていないスライドの中へフォーカスが移らないかを確かめる。

## サンプル

```html
<ul class="carousel-slides">
  <li class="carousel-slide">
    <a href="/news/1/">…</a>
  </li>
  <!-- 表示中でないスライド -->
  <li class="carousel-slide" inert>
    <a href="/news/2/">…</a>
  </li>
</ul>
```
