# 回避策と意図的な値には、理由と外す条件をコメントに残す

- 強さ: 必須
- 対象: ブラウザの不具合への回避策、デザインに合わせて調整した値、実行の順番への依存、`!important` など例外的な書き方。

一見すると不要に見える書き方には、理由をコメントに書く。回避策には、どのブラウザのどの問題に対するものかと、外せる条件（対応するブラウザの版が上がったら外す、など）を書く。

理由: 理由のない回避策は、後から読んだ人や AI に不要なコードと判断されて消され、直したはずの不具合が戻る。逆に、外せる条件が書いていないと、不要になった回避策がいつまでも残る。

例外・代替: なし。

- 構築: 調べて分かった問題の資料（不具合の報告の URL など）があれば、コメントに書く。
- レビュー: 理由の分からない書き方を見つけたら、消す前に経緯を確認する。
