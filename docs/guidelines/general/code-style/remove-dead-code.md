# 使っていないコード、コメントアウトしたコード、デバッグ用の出力を残さない

- 強さ: 必須
- 対象: 作業を終える前のコード。

使われなくなった関数・変数・スタイル、コメントアウトしたコード、確認のための `console.log` などは、作業の最後に削除する。

理由: 残ったコードは、使われているかどうかを読む人が毎回確かめることになる。デバッグ用の出力は、利用者のブラウザのコンソールに内部の情報を出す。

例外・代替: 失敗を記録するための出力など、運用で必要なものは残してよい。消したコードは変更の履歴から戻せるので、念のために残さない。

- 構築: 作業の最後に、自分が追加したデバッグ用の出力とコメントアウトを検索する。
- レビュー: 差分の中に、コメントアウトしたコードや `console.log` がないかを確認する。
