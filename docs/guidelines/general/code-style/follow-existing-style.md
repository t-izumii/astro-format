# 既存のコードの書き方と名前の付け方に合わせる

- 強さ: 必須
- 対象: 既存のコードに追加・変更する場合。

新しく書くコードは、周りの既存のコードの書き方、名前の付け方、ファイルの分け方に合わせる。より良いと思う書き方があっても、依頼の範囲で書き方を混在させない。

理由: 同じ案件の中で書き方が混ざると、読む人はどちらが正しいのかを判断できず、次に書く人がさらに別の書き方を足していく。

例外・代替: 既存の書き方に不具合や安全上の問題がある場合は、それに合わせず、問題を報告する。書き方そのものを変えたい場合は、別の作業として提案する。

- 構築: 書き始める前に、同じ種類の既存のファイルを読む。
- レビュー: 追加されたコードが、周りのコードと違う書き方をしていないかを確認する。
