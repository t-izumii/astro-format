# 部品の使い方を変えたら、すべての利用箇所を直す

- 強さ: 必須
- 対象: 部品が受け取る値、クラス名、イベント名、構造を変更する場合。

部品の使い方を変えるときは、その部品を使っている箇所をすべて検索し、新しい使い方に合わせて直す。直せない箇所がある場合は、古い使い方も動くように残し、残した理由と削除の条件をコメントに書く。

理由: 一部の利用箇所だけが古い使い方のまま残ると、そのページだけ表示が崩れたり、操作が効かなくなったりする。変更した本人が見ていないページで起きるため、気づきにくい。

例外・代替: なし。

- 構築: 変更の前に、部品の名前、クラス名、受け取る値の名前でコード全体を検索する。
- レビュー: 変更された部品の利用箇所がすべて新しい使い方になっているかを確認する。
