# 同じ部品を複数置いても、状態を共有させない

- 強さ: 必須
- 対象: 1ページに複数置かれうる部品。

開閉の状態、選択中の項目、タイマーなど、部品の状態は部品ごとに持つ。ファイルの最上位の変数など、すべての部品から共有される場所に状態を置かない。

理由: 状態を共有すると、1つの部品を操作したときに、別の部品の表示や動作まで変わる。

例外・代替: 「同時に1つだけ開く」のように、部品同士の連動が仕様の場合は、連動を管理する親の部品に状態を持たせる。

- 構築: 状態は、部品を初期化するときに作り、その部品の処理の中だけで使う。
- レビュー: 同じ部品を2つ置いたページで、片方の操作がもう片方に影響しないかを確かめる。
