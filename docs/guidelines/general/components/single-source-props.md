# 同じ事実を複数の入力で指定させない

- 強さ: 推奨
- 対象: 部品が受け取る値を設計・追加する場合。

部品が受け取る値は、1つの事実につき1つにする。開閉なら「開いているか」だけを受け取り、「閉じているか」を別に受け取らない。他の値から決まるもの（件数から決まる「空かどうか」など）は、部品の中で求める。

理由: 同じ事実を2つの値で受け取ると、矛盾した組み合わせ（開いていて、かつ閉じている）を渡せてしまい、どちらが優先されるかが部品を読まないと分からない。

例外・代替: なし。

- 構築: 値を足す前に、既存の値から求められないかを確認する。
- レビュー: 部品が受け取る値に、矛盾した組み合わせを作れるものがないかを確認する。
