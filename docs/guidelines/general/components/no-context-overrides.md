# 置かれた場所のセレクタで、部品の中身を上書きしない

- 強さ: 必須
- 対象: 置く場所によって部品の見た目を変えたい場合。

`.sidebar .card-title` のように、置かれた場所のセレクタから部品の中の要素を上書きしない。見た目の違いは、部品が受け取る値（バリエーションを表す属性やクラス、カスタムプロパティなど）で切り替える。

理由: 置かれた場所からの上書きは、部品の中の構造に依存しているため、部品の構造を変えると黙って効かなくなる。部品を読んでも、どこで見た目が変わっているかが分からない。

例外・代替: 外部のライブラリの部品で、受け取る値が用意されていない場合は、上書きしてよい。その場合は、上書きの理由をコメントに残す。

- 構築: 置く場所ごとの違いが必要になったら、部品の側にバリエーションを足す。
- レビュー: 部品の外のスタイルが、部品の中の要素を指していないかを確認する。
