# 部品に外側の余白と配置を持たせない

- 強さ: 必須
- 対象: 複数の場所に置かれる部品。

部品自身には、外側の `margin`、`position` による配置、置かれる場所に依存した幅を持たせない。部品同士の間隔や並べ方は、部品を置く側で決める。

理由: 部品に外側の余白を持たせると、置く場所ごとにその余白を打ち消す指定が必要になり、部品を動かすたびに崩れる。

例外・代替: 部品の内側の余白（`padding`）や、部品の中の要素同士の間隔は、部品が持つ。置く側から余白を指定できるように、部品が受け取る値として用意してもよい。

- 構築: 部品のいちばん外側の要素に `margin` を付けない。
- レビュー: 部品のいちばん外側の要素に、外側の余白や配置の指定がないかを確認する。
