# 新しい部品を作る前に、既存の部品を探して使う

- 強さ: 必須
- 対象: UI を追加する場合。

新しく部品を作る前に、同じ役割の部品がないかを探す。あれば、その部品をそのまま使うか、用意されているバリエーションで表す。既存の部品を複製して少しだけ変えた部品を作らない。

既存の部品を拡張するか新しく作るかは、次で判断する。

- 中身の構造が同じで、色や大きさなどの見た目が違うだけ → 既存の部品のバリエーションとして足す
- 構造や操作が大きく違い、バリエーションにすると条件分岐だらけになる → 新しい部品として作る

理由: 複製した部品は、元の部品を直しても直らず、似た部品が増えるほど見た目や動作の食い違いが広がる。

例外・代替: 既存の部品の中身が変更の予定と合わない場合は、作業の前に担当者へ確認する。

- 構築: 部品を置いているフォルダや部品の一覧を先に読む。
- レビュー: 新しく追加された部品に、既存の部品と同じ役割のものがないかを確認する。
