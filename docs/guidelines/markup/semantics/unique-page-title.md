# ページごとに、内容を表す title を付ける

- 強さ: 必須
- 対象: すべてのページ。
- WCAG: 2.4.2 A

`title` には、そのページの内容を表す名前を書く。ページ固有の名前を先に、サイト名を後に置く。画面を書き換えて表示を切り替える作りでは、表示が変わるたびに `title` も更新する。

理由: `title` は、タブの名前、ブックマーク、検索結果、スクリーンリーダーがページを開いたときの読み上げに使われる。全ページが同じ `title` だと、利用者は今どのページにいるかを区別できない。

例外・代替: なし。

- 構築: テンプレートで `title` を固定せず、ページごとに値を受け取れるようにする。
- レビュー: 複数のページを開き、タブの名前で区別できるかを確かめる。
