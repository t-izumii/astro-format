# 新しいタブで開くリンクは、そのことを伝える

- 強さ: 推奨
- 対象: `target=\"_blank\"` を付けるリンクと、ファイルをダウンロードするリンク。

新しいタブで開くことや、ファイルの形式と大きさを、リンクの文字かアイコンの代替テキストで伝える。`target="_blank"` を付けるときに `rel="noopener"` を足す必要はない。リンク先にどのページから来たかを伝えたくない場合だけ、`rel="noreferrer"` を付ける。

理由: 予告なく新しいタブが開くと、戻るボタンで元のページに戻れず、スクリーンリーダーの利用者や認知に障害のある利用者が混乱する。現在のブラウザでは、`target="_blank"` だけで `rel="noopener"` と同じ保護が働く。

例外・代替: なし。

- 構築: 新しいタブで開くかどうかは案件の方針に従い、リンクごとにばらばらにしない。
- レビュー: `target="_blank"` のリンクに、新しいタブで開くことが伝わる文字か代替テキストがあるかを確認する。
