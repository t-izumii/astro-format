# ページの移動はリンク、その場の操作はボタンにする

- 強さ: 必須
- 対象: クリックやタップで動く要素。
- WCAG: 4.1.2 A

別のページやページ内の位置へ移動するものは `a` 要素に `href` を付けて作る。開閉、送信、切り替えなどその場の操作は `button` 要素で作る。`href="#"` や `href="javascript:void(0)"` のリンクにクリック処理を付けて、ボタンの代わりにしない。

理由: リンクとボタンは、支援技術に伝わる役割が違い、ブラウザの機能（新しいタブで開く、URL をコピーする）も違う。ボタンの代わりにしたリンクは、新しいタブで開くと空のページが開くなど、利用者が予想しない動きになる。`href` のない `a` 要素はリンクとして扱われず、Enter で実行できない。

例外・代替: なし。

- 構築: 見た目がボタンでも、移動するものはリンクで作り、見た目を CSS で整える。
- レビュー: `href="#"`、`javascript:`、`href` のない `a` を検索し、ボタンにすべきものがないかを確認する。
