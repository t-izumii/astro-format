# html 要素に lang 属性を書く

- 強さ: 必須
- 対象: すべてのページ。
- WCAG: 3.1.1 A

`html` 要素に、ページの主な言語を `lang` 属性で書く。日本語のページなら `lang="ja"`。

理由: スクリーンリーダーは `lang` を見て読み上げの言語を切り替える。テンプレートの既定の `lang="en"` のまま日本語を書くと、英語の発音で読まれる。ブラウザの翻訳機能や、フォントの選択にも使われる。

例外・代替: ページの一部が別の言語なら、その部分の要素にも `lang` を付ける。

- 構築: 雛形やフレームワークの初期設定の `lang` を確認し、ページの言語に合わせる。
- レビュー: `html` 要素の `lang` がページの言語と一致しているかを確認する。
