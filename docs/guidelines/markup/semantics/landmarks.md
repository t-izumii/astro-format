# ランドマークを使い、同じ種類が複数あるときは名前で区別する

- 強さ: 必須
- 対象: すべてのページ。
- WCAG: 1.3.1 A

ページの領域を `header`、`nav`、`main`、`footer` で表す。`main` はページに1つだけにする。`nav` のように同じ種類が複数ある場合は、`aria-labelledby` か `aria-label` で「メイン」「パンくず」のように名前を付けて区別する。

理由: スクリーンリーダーの利用者は、ランドマークの一覧から目的の領域へ移動する。名前のない `nav` が複数あると、どれがどのナビゲーションか分からない。

例外・代替: リンクの集まりをすべて `nav` にする必要はない。フッターのリンク一覧など、主要なナビゲーションでないものは `nav` にしなくてよい。

- 構築: ページの雛形で、ランドマークの構成を先に決めておく。
- レビュー: ランドマークの一覧を出し、`main` が1つか、同じ種類のものに区別できる名前があるかを確かめる。
