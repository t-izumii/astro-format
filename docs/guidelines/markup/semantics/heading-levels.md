# 見出しのレベルは、見た目の大きさではなく内容の階層で選ぶ

- 強さ: 必須
- 対象: すべての見出し。
- WCAG: 1.3.1 A

見出しのレベルは、内容の親子関係で決める。ページの主題を `h1` にし、その下の節を `h2`、さらにその下を `h3` とする。文字を大きくしたいだけで見出しにしない。見出しのレベルを飛ばさない。

理由: スクリーンリーダーの利用者は、見出しの一覧とレベルでページの構造を把握し、目的の節へ移動する。見た目に合わせて選んだレベルは、構造を誤って伝える。

例外・代替: デザイン上の大きさとレベルが合わない場合は、正しいレベルの要素を使い、大きさを CSS で調整する。

- 構築: 部品の中に見出しを持たせる場合は、置かれる場所によってレベルが変わることを考え、レベルを変えられるようにする。
- レビュー: 開発者ツールなどで見出しの一覧を出し、内容の階層と一致しているかを確かめる。
