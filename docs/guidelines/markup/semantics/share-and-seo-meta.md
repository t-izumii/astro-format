# 共有と検索のための情報を、ページごとに書く

- 強さ: 推奨
- 対象: 公開するページ。

`meta name="description"`、OGP（`og:title`・`og:description`・`og:image`・`og:url`）、`link rel="canonical"` を、ページごとの値で書く。

理由: 全ページで同じ値だと、SNS で共有したときや検索結果で、どのページか区別できない。同じ内容に複数の URL がある場合、`canonical` がないと、どの URL を正とするかを検索エンジンに伝えられない。

例外・代替: 会員専用のページなど、共有も検索もされないページは省いてよい。

- 構築: テンプレートで、ページごとの値を受け取り、未指定ならサイト共通の値を使う仕組みにする。
- レビュー: 複数のページで、これらの値がページごとに変わっているかを確認する。
