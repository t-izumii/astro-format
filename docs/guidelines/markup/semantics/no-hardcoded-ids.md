# 繰り返し使う部品の中で id を固定しない

- 強さ: 必須
- 対象: 1ページに複数置かれうる部品の中で、`id` を使う場合。

`label` の `for`、`aria-labelledby`、`aria-describedby`、`aria-controls` などで参照する `id` は、部品を置くたびに異なる値になるようにする。

理由: 同じ `id` が複数あると、参照は最初の要素にしか結び付かない。2つ目以降の部品では、ラベルをクリックしても別の部品の入力欄にフォーカスが移り、説明も別の部品のものが読まれる。

例外・代替: ページに1つしか置かないことが決まっている部品は、固定の `id` でよい。

- 構築: 部品ごとに一意の接頭辞を受け取るか生成し、内部の `id` に付ける。
- レビュー: 同じ部品を2つ置いたページで、`id` が重複していないかを確認する。
