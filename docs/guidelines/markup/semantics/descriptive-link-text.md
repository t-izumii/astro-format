# リンクの文字だけで、行き先が分かるようにする

- 強さ: 必須
- 対象: すべてのリンク。
- WCAG: 2.4.4 A

リンクの文字は、リンク先の内容を表す言葉にする。「こちら」「詳しくはこちら」「もっと見る」「クリック」だけのリンクにしない。画像だけのリンクは、画像の `alt` に行き先を書く。URL をそのままリンクの文字にしない。

理由: スクリーンリーダーの利用者は、リンクだけを一覧にして読んだり、Tab でリンクからリンクへ移動したりする。そのとき「こちら」が並ぶと、どれがどこへ行くのか分からない。検索エンジンも、リンクの文字からリンク先の内容を読み取る。

例外・代替: 一覧のカードのように、デザイン上「詳しく見る」を繰り返す場合は、画面に表示しない文字で対象を補う。見えている文字は残す（[操作要素には、見えている文字を含む名前を付ける](../../accessibility/aria/visible-label-in-name.md)）。カード全体をリンクにして、見出しをリンクの文字にしてもよい。

- 構築: 文章の中では、「資料は[こちら]」と書かず、「[サービス紹介の資料]をダウンロードできる」のように、内容を表す言葉をリンクにする。
- レビュー: リンクの文字だけを順に読み、行き先が分かるかを確かめる。同じ文字のリンクが別々のページへ向いていないかも見る。

## サンプル: 繰り返す「詳しく見る」に対象を補う

```html
<!-- 問題例: どの商品の詳細か、リンクの文字から分からない -->
<a href="/items/1/">詳しく見る</a>

<!-- 改善例: 画面に表示しない文字で対象を補う -->
<a href="/items/1/">詳しく見る<span class="visually-hidden">（商品A）</span></a>
```
