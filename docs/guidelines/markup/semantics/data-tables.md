# データの表は table で作り、見出しのセルを th にする

- 強さ: 必須
- 対象: 行と列の関係で読むデータ（料金表、仕様の比較、時刻表など）。
- WCAG: 1.3.1 A

データの表は `table` 要素で作り、行や列の見出しのセルを `th` にする。見出しが行と列のどちらに対するものかが分かりにくい場合は、`scope` を付ける。表の内容を表す題名は `caption` に書く。

理由: `div` で表の見た目を作ると、スクリーンリーダーで読んだときに、セルの値がどの行・列の項目かが伝わらない。

例外・代替: レイアウトのために `table` を使わない。見た目が表でも、行と列の関係がない並びは、リストなどで作る。

- 構築: 画面の幅が狭いときは、表を崩さず、表の領域だけを横にスクロールさせる方法を先に検討する。
- レビュー: 行と列の関係で読む内容が `table` で作られ、見出しのセルが `th` になっているかを確認する。
