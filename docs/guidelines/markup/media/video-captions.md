# 音声を含む動画には字幕を用意する

- 強さ: 必須
- 対象: 録画済みで、話し声などの音声を含む動画。
- WCAG: 1.2.2 A

音声を含む動画には字幕を付ける。`video` 要素なら `track` 要素（`kind="captions"`）で字幕のファイルを読み込むか、映像に字幕を焼き込む。外部の動画サービスを埋め込む場合は、そのサービスの字幕を有効にする。

理由: 字幕がないと、聴覚に障害のある利用者や、音を出せない環境の利用者に内容が伝わらない。

例外・代替: ページの文章と同じ内容を動画にしたもので、そのことが明示されている場合は対象外。音声のない装飾の動画も対象外。

- 構築: 字幕のファイルを誰が用意するかを、制作の初期に確認する。
- レビュー: 音声を含む動画で、字幕を表示できるかを確かめる。
