# 最初の画面に表示される画像は、遅延読み込みにしない

- 強さ: 推奨
- 対象: `loading` 属性を付ける画像。

`loading="lazy"` は、最初の画面の外にある画像だけに付ける。メインビジュアルなど、最初の画面で最も大きく表示される画像には `loading="lazy"` を付けず、`fetchpriority="high"` を付けてよい。

理由: 遅延読み込みは、画像が画面のどこにあるかが分かるまで読み込みを始めないため、最初の画面の画像に付けると表示が遅れる。

例外・代替: 画面の幅によって最初の画面に入るかどうかが変わる画像は、小さい画面を基準に判断する。

- 構築: 部品の中の画像に `loading="lazy"` を固定で付けず、置かれる位置で切り替えられるようにする。
- レビュー: 最初の画面に表示される画像に `loading="lazy"` が付いていないかを確認する。
