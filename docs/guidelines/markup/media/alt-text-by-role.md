# 代替テキストは、画像の役割に合わせて書き分ける

- 強さ: 必須
- 対象: `img` 要素と、`role=\"img\"` を付けた要素。
- WCAG: 1.1.1 A

代替テキストは、画像がページの中で果たしている役割に合わせて書く。

| 画像の役割 | `alt` に書くこと |
|---|---|
| 内容や意味を伝える写真・図 | 伝えたい内容を短く書く |
| リンクやボタンの中にあり、それだけで行き先や動作を示す画像 | 行き先や動作（「トップページへ」「検索」） |
| 文字を画像にしたもの | 画像の中の文字 |
| グラフなど情報量の多い図 | 短い説明を書き、詳しい内容は本文に書く |
| 装飾、または隣に同じ内容の文字がある画像 | 空にする（`alt=""`） |

`alt` 属性そのものは省かない。

理由: `alt` がないと、スクリーンリーダーがファイル名を読み上げることがある。装飾の画像に説明を書くと、利用者は意味のない読み上げを聞かされる。リンクの中の画像に見た目の説明を書くと、どこへ移動するかが伝わらない。

例外・代替: CMS で入稿される画像は、入稿の画面で代替テキストを入力できるようにし、未入力の場合の扱い（空にするか、入力を必須にするか）を決める。

- 構築: 画像を置くたびに、上の表のどれに当たるかを判断する。「〜の画像」「写真:」のような前置きは書かない。画像であることは支援技術が伝える。
- レビュー: 画像を非表示にした状態で、代替テキストだけで内容と操作が伝わるかを確かめる。
