# 意味を持つ SVG には名前を付け、装飾の SVG は支援技術から隠す

- 強さ: 必須
- 対象: HTML の中に直接書いた `svg` 要素。
- WCAG: 1.1.1 A

意味を持つ SVG（単独で情報を伝えるアイコンやロゴ）には、`role="img"` と `aria-label` を付ける。装飾の SVG や、隣の文字と同じ意味のアイコンには、`aria-hidden="true"` を付ける。

理由: 直接書いた `svg` は、名前を付けないと支援技術に何も伝わらないか、中の図形の情報が無意味に読み上げられる。

例外・代替: SVG を `img` 要素の `src` で読み込む場合は、他の画像と同じく `alt` で扱う。

- 構築: アイコンの部品は、意味を持つか装飾かを受け取って、属性を切り替えられるようにする。
- レビュー: `svg` を検索し、`aria-label` か `aria-hidden` のどちらかが付いているかを確認する。
