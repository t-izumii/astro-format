# srcset で幅の違う画像を渡すときは、sizes を書く

- 強さ: 必須
- 対象: `srcset` に幅（`w`）を書く画像。

`srcset` に幅の違う画像を並べるときは、`sizes` に画面上での表示の幅を書く。表示の幅がレイアウトで変わる場合は、メディアクエリと組み合わせて書く。

理由: `sizes` を省くと、ブラウザは画像が画面の幅いっぱい（`100vw`）に表示されるものとして選ぶ。小さく表示する画像でも、大きな画像が読み込まれる。

例外・代替: 表示の大きさが決まっていて、解像度の違いだけを出し分ける場合は、`srcset` に `1x`・`2x` を書けばよく、`sizes` は不要。

- 構築: `sizes` の値は、CSS のレイアウトから実際の表示の幅を確認して決める。
- レビュー: 開発者ツールで、表示の大きさに対して大きすぎる画像が読み込まれていないかを確かめる。

## サンプル: 一覧のカードの画像

前提: 画面の幅 768px 以上ではカードが3列で、それより狭い画面では1列。

```html
<img
  src="card-800.jpg"
  srcset="card-400.jpg 400w, card-800.jpg 800w, card-1200.jpg 1200w"
  sizes="(min-width: 768px) 33vw, 100vw"
  width="800"
  height="600"
  alt="新しいオフィスの受付"
  loading="lazy"
/>
```
