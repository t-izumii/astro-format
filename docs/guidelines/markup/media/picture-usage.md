# picture は、形式の出し分けか、画面によって画像を差し替える場合に使う

- 強さ: 推奨
- 対象: `picture` 要素を使うかどうかを決める場合。

`picture` は、新しい画像形式を対応するブラウザにだけ渡す場合と、画面の幅によって切り抜きや構図の違う画像に差し替える場合に使う。同じ画像の大きさ違いを出し分けるだけなら、`img` の `srcset` と `sizes` で足りる。

理由: 必要のない `picture` は記述を増やし、`sizes` の書き漏れなどの誤りを増やす。

例外・代替: 対象のブラウザがすべて対応している形式だけを使う場合は、形式の出し分けのための `picture` は不要。

- 構築: `picture` を使う場合も、代替テキストと `width`・`height` は中の `img` に書く。
- レビュー: 大きさ違いの出し分けだけに `picture` を使っていないかを確認する。
