# 画像には width と height を書く

- 強さ: 必須
- 対象: すべての `img` 要素。

`img` 要素に、画像の元の大きさを `width` と `height` 属性で書く。画面に合わせて縮める場合は、CSS で `max-width: 100%` と `height: auto` を指定する。

理由: `width` と `height` があれば、ブラウザは画像を読み込む前に縦横比を計算して場所を確保する。書かないと、画像を読み込んだときに下の内容が押し下げられ、読んでいた位置や押そうとしたボタンがずれる。

例外・代替: CSS の `aspect-ratio` で枠の大きさを決めている場合も、`width` と `height` は書いておく。

- 構築: CMS から出力する画像も、画像の大きさを取得して属性に書く。
- レビュー: 通信を遅くした状態でページを読み込み、画像の読み込みで内容がずれないかを確かめる。
