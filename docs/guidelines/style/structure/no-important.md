# !important を使わない

- 強さ: 必須
- 対象: すべてのスタイル。

`!important` で上書きの問題を解決しない。

理由: `!important` を付けた指定は、さらに `!important` を付けないと上書きできず、問題を先送りするだけになる。`@layer` を使っている場合は、`!important` を付けるとレイヤーの優先順位が逆になり、結果を予測しにくい。

例外・代替: 次の場合は使ってよい。どの場合も、使う理由をコメントに残す。

- 常に優先させることが目的の補助クラス（画面に表示しない文字のクラスなど）
- 外部のスクリプトが要素に直接書き込むスタイルを上書きする場合
- 利用者の設定（動きを抑える設定など）に合わせて、ページ全体の動きを止める場合

- 構築: `!important` が必要に見えたら、上の「詳細度を上げない」と同じ手順で原因を確かめる。
- レビュー: `!important` を検索し、例外に当たらないものがないかを確認する。
