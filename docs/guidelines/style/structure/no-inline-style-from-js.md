# スクリプトから見た目を変えるときは、style を直接書き換えない

- 強さ: 推奨
- 対象: スクリプトで表示や見た目を切り替える処理。

`element.style.display = 'none'` のように、スクリプトで個々のスタイルを書き換えない。属性やクラスを切り替え、見た目は CSS に書く。スクロール量など、スクリプトで計算した値を使う場合は、カスタムプロパティに値を渡す。

理由: スクリプトの中に見た目の指定が散らばると、CSS だけを読んでも表示が分からず、要素に直接書かれた指定は CSS から上書きしにくい。

例外・代替: ドラッグ中の位置など、フレームごとに変わる値は、カスタムプロパティか `transform` を直接更新してよい。

- 構築: スクリプトから CSS へ渡す値は、`element.style.setProperty('--progress', value)` のようにカスタムプロパティにする。
- レビュー: `.style.` を検索し、属性やクラスの切り替えで書けるものがないかを確認する。
