# 状態の見た目は、状態を表す属性に連動させる

- 強さ: 推奨
- 対象: 開閉、選択、現在地、無効、エラーなど、状態によって見た目が変わる要素。

状態の見た目は、`[aria-expanded="true"]`、`[aria-current="page"]`、`[aria-invalid="true"]`、`:disabled`、`:checked` のように、状態を表す属性や疑似クラスをセレクタにして書く。見た目のためだけのクラスを別に切り替えない。

理由: 見た目用のクラスと状態の属性を別々に切り替えると、片方の更新漏れで、見た目と支援技術に伝わる状態が食い違う。属性をセレクタにすれば、属性を更新するだけで見た目も変わる。

例外・代替: スクロールに応じてヘッダーを縮めるなど、対応する属性がない見た目だけの状態は、クラスや data 属性で表してよい。

- 構築: 状態を変える処理では属性だけを更新し、見た目は CSS に任せる。
- レビュー: 状態を表すクラスと ARIA の属性が両方切り替わっている箇所を探し、属性のセレクタにまとめられないかを確認する。

## サンプル: 開閉ボタンの矢印を状態に連動させる

```css
/* 問題例: aria-expanded と別に、見た目用のクラスを切り替えている */
.accordion-button.active .icon {
  rotate: 180deg;
}

/* 改善例 */
.accordion-button[aria-expanded="true"] .icon {
  rotate: 180deg;
}
```
