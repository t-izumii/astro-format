# 部品のスタイルを、要素セレクタや広い範囲の指定で書かない

- 強さ: 必須
- 対象: 部品やページの一部に向けたスタイル。

部品のスタイルは、その部品のクラスなどで対象を絞って書く。`img`、`p`、`.section p` のように、他の場所の要素にも当たる指定で書かない。

理由: 広い指定は、意図していない場所の要素にも効き、後から追加した部品の見た目を壊す。どこに効いているかを確かめる手間も増える。

例外・代替: リセットや文字の基本設定など、ページ全体に効かせることが目的の指定は、要素セレクタで書いてよい。その場合は `:where()` で囲んで詳細度を 0 にし、部品側の指定で簡単に上書きできるようにする。

- 構築: 新しく書くセレクタが、他にどの要素に当たるかを確認する。
- レビュー: 要素セレクタや、子孫セレクタで要素を指す指定を探し、意図しない場所に効いていないかを確認する。
