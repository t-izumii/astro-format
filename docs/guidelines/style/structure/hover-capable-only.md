# ホバーの見た目は、ホバーできる端末に限って付ける

- 強さ: 推奨
- 対象: ホバーで色や形を変える指定。

ホバーの見た目は `@media (hover: hover)` の中に書く。

理由: タッチ端末では、タップした要素にホバーの見た目が残り、選択されたように見えることがある。

例外・代替: ホバーしたときに補足の内容を表示する場合は、ホバーできない端末でも同じ内容に到達できる方法を用意する。

- 構築: ホバーとフォーカスで同じ見た目にしたい場合も、フォーカスの見た目はホバーの条件の外に書く。
- レビュー: タッチ端末のエミュレーションでタップし、ホバーの見た目が残らないかを確かめる。
