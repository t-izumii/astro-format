# 共通の指定を変えるときは、使われている箇所をすべて確かめる

- 強さ: 必須
- 対象: 共通のクラス、基本のスタイル、カスタムプロパティを変更する場合。

共通の指定を変える前に、使われている箇所をすべて検索し、変更後の見た目を確かめる。一部の箇所だけを変えたい場合は、共通の指定を変えず、その箇所だけの指定を足す。

理由: 共通の指定は、変更した本人が見ていないページにも効く。一つの画面のために変えると、他の画面が崩れる。

例外・代替: 全体の見た目をそろえて変えることが目的の場合は、共通の指定を変えてよい。その場合も、影響する画面を確かめる。

- 構築: 変更の前に、クラス名やカスタムプロパティ名でコード全体を検索する。
- レビュー: 共通の指定の変更について、影響する箇所が確認されているかを確かめる。
