# 既存の指定に勝つために詳細度を上げない

- 強さ: 必須
- 対象: 既存のスタイルを上書きする場合。

上書きできないときに、ID セレクタ、要素名やクラスの重ね書き（`div.card`、`.list .item .title`）、入れ子の追加で詳細度を上げて勝とうとしない。元の指定の範囲を絞るか、読み込み順やカスケードレイヤー（`@layer`）で順番を決める。

理由: 詳細度を上げて勝つと、次に上書きしたい人がさらに詳細度を上げることになり、指定が際限なく複雑になる。

例外・代替: 既存の CSS がレイヤーを使っていない案件で `@layer` を導入するときは注意する。レイヤーに入っていない指定は、レイヤーに入った指定より常に優先されるため、新しく書いた指定がレイヤーの中にあると、既存の指定に負ける。

- 構築: 上書きできない原因を開発者ツールで確かめ、元の指定を直せないかを先に検討する。
- レビュー: ID セレクタ、要素名とクラスの重ね書き、深い入れ子を探す。
