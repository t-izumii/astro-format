# 並んだ要素の間隔は gap で付ける

- 強さ: 推奨
- 対象: Flexbox や Grid で並べた要素の間隔。

並んだ要素の間隔は、親に `gap` を指定して付ける。子要素に `margin` を付けて、最後の要素だけ打ち消す書き方をしない。

理由: `gap` は要素の間にだけ間隔を作るので、折り返しや並び替えのときも端に余分な余白が残らない。

例外・代替: 一部の要素の間だけ間隔を変えたい場合は、その要素に `margin` を付けてよい。

- 構築: 間隔の値はトークンを使う。
- レビュー: `:last-child` や `:first-child` で余白を打ち消している箇所がないかを確認する。
