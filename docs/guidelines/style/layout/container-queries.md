# 配置先の幅で形を変える部品は、コンテナクエリで切り替える

- 強さ: 推奨
- 対象: 同じ部品を、本文とサイドバーなど幅の違う場所に置く場合。

部品の形を、画面の幅ではなく配置先の幅で切り替える場合は、コンテナクエリを使う。`container-type: inline-size` は、幅が親や指定で決まる要素に付ける。

理由: メディアクエリは画面の幅しか見ないので、同じ画面幅でも配置先によって狭い場所に置かれた部品が崩れる。`container-type: inline-size` を付けた要素は、中身から幅を決めなくなるため、中身に合わせて幅が決まる要素（幅を指定していない横並びの子要素など）に付けると、幅が潰れることがある。

例外・代替: ページ全体のレイアウトの切り替えは、メディアクエリでよい。

- 構築: コンテナにする要素は、部品の外側の要素（配置先）にする。
- レビュー: 同じ部品を幅の違う場所に置いて、それぞれで形が切り替わるかを確かめる。
