# 内容の量が変わっても崩れないようにする

- 強さ: 必須
- 対象: CMS や API から内容が入る領域、一覧、カード。

想定より長い文章、改行のない長い英単語や URL、0件、大量の件数、画像がない場合のそれぞれで、レイアウトが崩れないようにする。長い英単語や URL は `overflow-wrap: anywhere` などで折り返す。画像を置く枠には `aspect-ratio` を指定し、画像が読み込めないときも枠の大きさを保つ。

理由: デザインのサンプルの文章や件数は、実際の運用で入る内容と違う。崩れはサイトの公開後、内容が更新されたときに初めて表に出る。

例外・代替: 入力の段階で文字数などが制限されている場合は、その上限で確かめればよい。

- 構築: 実装したら、長い文章、短い文章、0件、多い件数、画像なしの内容を入れて確かめる。
- レビュー: 上の条件で表示を確かめた記録があるかを確認し、なければ自分で確かめる。
