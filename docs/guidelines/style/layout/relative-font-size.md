# 文字サイズは、利用者の文字サイズの設定が効く単位で書く

- 強さ: 必須
- 対象: 文字サイズの指定。
- WCAG: 1.4.4 AA

文字サイズは `rem` などの相対単位で書く。画面幅に合わせて文字サイズを変える場合は、`vw` だけで指定せず、`clamp()` の最小値と最大値を `rem` で書く。

理由: `px` で書いた文字サイズは、ブラウザの文字サイズの設定を変えても大きくならない。`vw` だけで書いた文字サイズは、ページを拡大しても大きくならず、拡大が必要な利用者が読めなくなる。

例外・代替: なし。

- 構築: デザインの px の値を `rem` に換算して書く。
- レビュー: ブラウザの既定の文字サイズを大きくした状態と、ページを 200% に拡大した状態で、文字が大きくなるかを確かめる。

## サンプル: 画面幅に合わせて変わる見出し

```css
/* 問題例: 拡大しても大きくならない */
h1 {
  font-size: 5vw;
}

/* 改善例 */
h1 {
  font-size: clamp(1.75rem, 1.25rem + 2.5vw, 3rem);
}
```
