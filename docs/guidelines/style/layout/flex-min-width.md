# 伸縮する並びの子要素は、内容の幅で縮まなくならないようにする

- 強さ: 必須
- 対象: Flexbox や Grid の子要素に、長い文字列や横にスクロールする要素が入る場合。

Flexbox と Grid の子要素は、既定では内容の最小の幅より小さく縮まない。横にスクロールする表やコードの例など、幅の広い要素を含む子要素には `min-width: 0` を指定して、親の幅に収まるようにする。

理由: 指定しないと、子要素が親の幅を押し広げ、ページ全体に横スクロールが出る。中の表に `overflow-x: auto` を付けていても、子要素が縮まないため表の領域だけをスクロールさせることができない。

例外・代替: 子要素自体がスクロールの領域（`overflow` に `visible` 以外を指定した要素）なら、既定の最小の幅は 0 になるので指定は不要。

- 構築: 本文の領域とサイドバーのような横並びで、本文側に `min-width: 0` を付けておく。
- レビュー: 本文に幅の広い表を入れたときに、ページに横スクロールが出ないかを確かめる。
