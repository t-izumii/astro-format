# 固定の高さで文字や内容を収めない

- 強さ: 必須
- 対象: 文字や、量が変わる内容を含む要素。

文字を含む要素に `height` で固定の高さを付けない。最低限の高さが必要なら `min-height` を使い、内容に合わせて伸びるようにする。

理由: 固定の高さは、文字を 200% に拡大したとき、利用者が行間や文字の間隔を広げたとき、想定より長い文章が入ったときに、文字を切り取ったり、次の内容に重ねたりする。

例外・代替: アイコンなど中身の大きさが決まっている要素は、固定の高さでよい。長い文章を省略記号で切り詰める場合は、全文を読める手段（詳細ページへのリンクなど）を用意する。

- 構築: デザインの高さをそのまま `height` にせず、余白と `min-height` で再現する。
- レビュー: 文字を 200% に拡大した状態と、行間を 1.5 倍・文字の間隔を 0.12 倍に広げた状態で、文字が切れたり重なったりしないかを確かめる。
