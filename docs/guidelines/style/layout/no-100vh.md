# 画面の高さに合わせる指定に 100vh を使わない

- 強さ: 推奨
- 対象: 最初の画面いっぱいに表示する領域など、画面の高さに合わせる指定。

画面の高さに合わせる場合は、`100vh` ではなく `100svh` か `100dvh` を使う。高さを安定させたい場合は `svh`、ブラウザのツールバーの表示に合わせて変えたい場合は `dvh` を使う。

理由: モバイルのブラウザでは、`vh` はツールバーが隠れたときの大きい画面を基準にするため、ツールバーが表示されている間は、`100vh` の領域の下端がツールバーに隠れる。`dvh` はツールバーの表示に合わせて変わるため、スクロール中にレイアウトが動くことがある。

例外・代替: `svh` と `dvh` は Chrome 108、Firefox 101、Safari 15.4 以降で使える。対象のブラウザにそれより古い版を含む場合は、先に `100vh` を書いてから上書きする。

- 構築: 高さを画面に合わせる場合も、内容が多いときに伸びるよう `min-height` で指定する。
- レビュー: モバイルの実機かエミュレーションで、領域の下端がツールバーに隠れないかを確かめる。
