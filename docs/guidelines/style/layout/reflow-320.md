# 幅 320px 相当まで縮めても、横スクロールなしで読めるようにする

- 強さ: 必須
- 対象: 縦にスクロールして読むページ。
- WCAG: 1.4.10 AA（2.1 で追加）

画面の幅を 320 CSS ピクセルにしても、横スクロールなしで内容を読み、操作できるようにする。要素に `width: 1200px` のような固定の幅を付けず、`max-width` と流動的な幅で組む。

理由: 400% に拡大して使う利用者の画面は、幅 320px 相当になる。横スクロールが必要になると、1行を読むたびに左右へ移動することになる。

例外・代替: データの表、地図、図、動画、ゲーム、操作中に表示し続ける必要があるツールバーなど、2次元の配置が意味を持つ内容は対象外。データの表は、表の領域だけを横にスクロールさせる。

- 構築: 実装したら、幅 320px の表示で確かめる。
- レビュー: 幅 320px で横スクロールが出ないか、内容が欠けていないかを確かめる。
