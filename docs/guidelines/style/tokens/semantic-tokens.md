# 部品からは、用途を表すトークンを参照する

- 強さ: 必須
- 対象: 基礎値（色の一覧など）と用途（本文の色、リンクの色など）の層に分けてトークンを定義している案件。

部品のスタイルからは、「リンクの色」「エラーの色」のように用途を表すトークンを参照する。基礎値のトークン（「青の600番」など）を部品から直接参照しない。

理由: 基礎値を直接参照すると、「リンクの色だけを変える」ときに、同じ青を使う他の用途まで一緒に変わってしまう。用途のトークンを通せば、変更の範囲を用途ごとに区切れる。

例外・代替: 用途のトークンがまだない値は、基礎値を直接参照せず、用途のトークンを追加する。追加が案件の決まりで制限されている場合は、担当者に確認する。

- 構築: 使いたい用途のトークンがない場合は、用途の層に追加してから参照する。
- レビュー: 部品のスタイルが基礎値のトークンを直接参照していないかを確認する。

## サンプル: 基礎値と用途の層

トークンの名前は説明のための例。

```css
:root {
  /* 基礎値 */
  --palette-blue-600: #1a5fb4;
  --palette-red-600: #c01c28;

  /* 用途 */
  --color-link: var(--palette-blue-600);
  --color-error: var(--palette-red-600);
}

/* 部品からは用途を参照する */
.notice-error {
  color: var(--color-error);
}
```
