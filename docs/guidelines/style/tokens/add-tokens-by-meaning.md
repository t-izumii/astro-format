# 新しいトークンは、同じ意味で使う値だけをまとめて作る

- 強さ: 推奨
- 対象: トークンを追加する場合。

トークンは、同じ意味で複数の箇所に使う値に作る。値がたまたま同じでも、意味が違うもの（ブランドの赤とエラーの赤など）は、別のトークンにする。

理由: 意味の違う値を1つのトークンにまとめると、片方だけを変えたいときに分けられない。1か所でしか使わない値までトークンにすると、一覧が膨らんで探しにくくなる。

例外・代替: なし。

- 構築: 追加する前に、既存のトークンに同じ意味のものがないかを確認する。
- レビュー: 追加されたトークンが複数の箇所で使われているか、意味の違う用途をまとめていないかを確認する。
