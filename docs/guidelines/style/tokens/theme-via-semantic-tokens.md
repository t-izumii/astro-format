# テーマの切り替えは、用途のトークンの値を差し替えて行う

- 強さ: 推奨
- 対象: ダークモードや、ブランドごとの配色の切り替えがある案件。

テーマごとに用途のトークンの値を差し替え、部品のスタイルにはテーマごとの指定を書かない。

理由: 部品ごとにテーマの指定を書くと、部品を追加するたびにテーマの数だけ指定が増え、対応漏れが起きる。

例外・代替: テーマによって形や配置まで変わる部品は、部品の側にテーマの指定を書いてよい。

- 構築: テーマで値が変わるものは、すべて用途のトークンとして定義する。
- レビュー: 部品のスタイルの中に、テーマを判定するセレクタやメディアクエリがないかを確認する。
