# 色・余白・文字サイズは、定義済みのトークンを使う

- 強さ: 必須
- 対象: トークンを定義している案件で、スタイルに値を書く場合。

値を書く前に、定義済みのトークンを探して使う。デザインの値がトークンと少しだけ違う場合は、新しい値を直書きせず、トークンに合わせてよいかをデザインの担当者に確認する。

理由: 値を直書きすると、デザインを変更するときに検索で拾いきれず、変更漏れが起きる。近いが少し違う値が増えると、見た目の統一も崩れる。

例外・代替: 1か所でしか使わず、他と連動して変わる理由もない値（特定の画像に合わせた位置の調整など）は、直書きしてよい。その場合は、なぜその値なのかをコメントに残す。

- 構築: トークンを定義したファイルを先に読み、使える値を把握してから書く。
- レビュー: 色のコード（`#`、`rgb(`）や px の値を検索し、トークンで書けるものがないかを確認する。
