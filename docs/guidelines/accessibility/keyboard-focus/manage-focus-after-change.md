# 開閉や削除のあとにフォーカスの行き先を決める

- 強さ: 必須
- 対象: 開いた内容を閉じる操作、フォーカスのある要素を削除・置き換える操作、画面の一部を差し替える操作。
- WCAG: 2.4.3 A

閉じたときは、開いたボタンにフォーカスを戻す。フォーカスのある要素を削除するときは、隣の項目や一覧の見出しなど、続きの操作がしやすい場所へ移す。開く操作では原則としてフォーカスを動かさず、モーダルのように他の操作を止める場合だけ、開いた内容の中へ移す。

理由: フォーカスのある要素が消えると、フォーカスはページの先頭（`body`）に戻り、利用者は最初から移動し直すことになる。

例外・代替: フォーカスを移す先が見出しなど操作できない要素の場合は、`tabindex="-1"` を付けてから移す。

- 構築: 要素を削除・置き換える処理では、削除の前に次のフォーカス先を決めておく。
- レビュー: 閉じる、削除する、絞り込む、ページを送る操作のあとに、フォーカスがどこにあるかを確かめる。

## サンプル: 一覧から項目を削除する

前提: 各項目に削除ボタンがあり、`listHeading` は一覧の見出しで `tabindex="-1"` を持つ。

```js
// 問題例: 削除したボタンと一緒にフォーカスが失われる
item.remove();

// 改善例: 隣の項目、なければ一覧の見出しへ移す
const next = item.nextElementSibling ?? item.previousElementSibling;
item.remove();
(next?.querySelector('button') ?? listHeading).focus();
```
