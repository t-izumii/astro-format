# 見た目の順番とフォーカスの順番をそろえる

- 強さ: 必須
- 対象: CSS で並び順や配置を変えている箇所。
- WCAG: 2.4.3 A

並び順を変えるときは、CSS の `order`、`flex-direction: row-reverse`、Grid の配置ではなく、HTML の順番を変える。

理由: CSS で見た目の順番だけを変えると、Tab での移動が見た目と違う順番で飛び、利用者が次の移動先を予測できなくなる。

例外・代替: 画面幅によって並び順を変える必要があり、HTML の順番を変えられない場合は、どの幅でも操作の意味が通る順番になっているかを確認する。

- 構築: 並び順を変えたいときは、まず HTML の順番を変えられないか検討する。
- レビュー: `order`、`*-reverse`、`grid-row`・`grid-column`・`grid-area` で操作要素を含む領域を動かしている箇所で、Tab の順番を確かめる。
