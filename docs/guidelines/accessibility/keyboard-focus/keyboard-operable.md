# クリックできるものはキーボードでも操作できるようにする

- 強さ: 必須
- 対象: クリックやタップで動く要素と、ホバーで表示される操作。
- WCAG: 2.1.1 A

クリック処理は、`button` や `href` 付きの `a` など、キーボードで到達・実行できる要素に付ける。ホバーしたときにだけ現れる操作を作らない。

理由: `div` や `span` にクリック処理を付けただけでは Tab で止まらず、キーボードの利用者は操作できない。

例外・代替: 自由に線を描くなど、ポインターの軌跡そのものが機能の本質である操作は対象外になる。ドラッグでの並べ替えは対象外にならないので、ボタンなどの代替手段を用意する。

- 構築: クリック処理を付ける要素が `button` か `a` かを確認する。独自の要素にする場合は、Tab での到達と、役割に合うキーでの実行を自分で実装する。
- レビュー: マウスを使わずに主要な操作を最後まで完了できるか、途中で抜け出せなくならないかを確かめる。
