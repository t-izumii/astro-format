# tabindex は 0 と -1 だけを使い分ける

- 強さ: 必須
- 対象: `tabindex` 属性を付ける場合。
- WCAG: 2.4.3 A

`tabindex` に 1 以上の値を使わない。`0` は、独自に作った操作要素を Tab で到達できるようにする場合だけに使う。`-1` は、スクリプトでフォーカスを移す先（Tab では止まらなくてよい見出しなど）に使う。

理由: 1 以上の値は HTML の順番より先に移動させるため、ページ全体の移動順が崩れる。操作できない要素に `0` を付けると、Tab で止まる場所が増えて移動に時間がかかる。

例外・代替: なし。

- 構築: 見出しや段落に `tabindex="0"` を付けて読ませようとしない。読み上げは Tab 以外の方法で到達できる。
- レビュー: `tabindex` を検索し、1 以上の値と、操作できない要素の `0` がないかを確認する。
