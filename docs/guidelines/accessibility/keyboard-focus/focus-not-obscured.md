# 固定表示の要素でフォーカスを隠さない

- 強さ: 必須
- 対象: 固定ヘッダー、固定フッター、Cookie の同意バナー、チャットの起動ボタンなど、スクロールしても画面に残る要素があるページ。
- WCAG: 2.4.11 AA（2.2 で追加）

Tab で移動した先の要素が、固定表示の要素の下に完全に隠れないようにする。固定ヘッダーがあるなら、`scroll-padding-top` にその高さを指定する。

理由: ブラウザはフォーカスした要素を画面内へスクロールするが、固定表示の要素の下に入ると利用者からは見えない。

例外・代替: なし。

- 構築: 固定表示の要素を追加したら、上下どちらに残るかに合わせて `scroll-padding-top` または `scroll-padding-bottom` を指定する。
- レビュー: ページの下から上へ Shift + Tab で戻り、フォーカスした要素が固定ヘッダーの下に隠れないかを確かめる。
