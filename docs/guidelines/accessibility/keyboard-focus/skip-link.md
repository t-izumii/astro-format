# 本文へ移動するスキップリンクを、ページの先頭に置く

- 強さ: 必須
- 対象: ヘッダーやナビゲーションなど、本文の前に繰り返し現れる操作要素があるページ。
- WCAG: 2.4.1 A

`body` の中で最初にフォーカスが当たる位置に、「本文へ移動」のリンクを置き、行き先を `main` の `id` にする。ふだんは画面に表示しなくてよいが、フォーカスが当たったときは見えるようにする。

理由: キーボードだけで操作する利用者は、ページを移るたびに、ヘッダーのリンクをすべて Tab で通り過ぎないと本文に着けない。スクリーンリーダーの利用者はランドマークで移動できるが、目で見てキーボードで操作する利用者には、その手段がない。

例外・代替: 本文の前に操作要素がほとんどないページ（ロゴのリンクだけのランディングページなど）では、置かなくてよい。

- 構築: スキップリンクを `display: none` や `visibility: hidden` で隠さない。フォーカスが当たらなくなる。画面の外に出しておき、`:focus` で画面の中に戻す。ページの雛形に入れておき、ページごとに書かない。
- レビュー: ページを開いて最初に Tab を押し、スキップリンクが見えるかを確かめる。Enter のあとに Tab を押し、本文の最初の操作要素へ進むかも確かめる。

## サンプル

```html
<body>
  <a class="skip-link" href="#main">本文へ移動</a>
  <header>…</header>
  <main id="main">…</main>
</body>
```

```css
.skip-link {
  position: absolute;
  inset-block-start: 0;
  inset-inline-start: 0;
  transform: translateY(-100%);
}

.skip-link:focus {
  transform: translateY(0);
}
```
