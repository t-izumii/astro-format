# フォーカスの表示を消さない

- 強さ: 必須
- 対象: フォーカスを受け取るすべての要素。
- WCAG: 2.4.7 AA

フォーカスの表示を消す指定（`outline: none` など）を、代わりの表示なしに書かない。独自の表示にする場合は、`:focus-visible` に `outline` で指定する。`box-shadow` だけで表示しない。

理由: 表示が消えると、キーボードの利用者は今どこにいるか分からなくなる。`box-shadow` は Windows のハイコントラストなど強制カラーモードで `none` に置き換えられるため、その環境では表示が消える。`outline` の色はシステムの色に置き換えられるだけで、表示は残る。

例外・代替: ブラウザの既定の表示をそのまま使う場合は、指定は不要。リセット CSS が `outline` を消していないかは確認する。

- 構築: `:focus` ではなく `:focus-visible` を使い、マウスでクリックしたときに枠が出る問題を消す目的で表示そのものを消さない。
- レビュー: Tab で移動して、すべての操作要素で表示が見えるかを確かめる。`outline: none` や `outline: 0` を検索し、代わりの表示があるかを確認する。

## サンプル: 強制カラーモードでも消えない表示

```css
/* 問題例: 既定の表示を消し、box-shadow だけで示している */
button:focus {
  outline: none;
  box-shadow: 0 0 0 3px rgb(0 95 204 / 0.6);
}

/* 改善例 */
button:focus-visible {
  outline: 3px solid rgb(0 95 204);
  outline-offset: 2px;
}
```
