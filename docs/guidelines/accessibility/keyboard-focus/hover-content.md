# ホバーで現れる内容はフォーカスでも表示し、Esc で閉じられるようにする

- 強さ: 必須
- 対象: ツールチップ、ホバーで開くサブメニューなど、ホバーやフォーカスで追加表示する内容。
- WCAG: 1.4.13 AA（2.1 で追加）

ホバーで表示する内容は、フォーカスでも表示する。表示した内容は、次の3つを満たす。

- ポインターやフォーカスを動かさずに、Esc などで閉じられる。
- ポインターを表示した内容の上に移しても消えない。
- 利用者が閉じるか、ポインター・フォーカスが外れるまで表示が続く。

理由: ホバーだけで表示する内容はキーボードの利用者に届かない。拡大して使う利用者は、表示した内容が他の内容を覆ったときに消す手段が必要になり、内容を読むためにポインターを動かすと消えてしまう表示も読めない。

例外・代替: 入力エラーを伝える表示や、他の内容を覆わない表示は、閉じる手段がなくてもよい。ブラウザが表示する `title` 属性のツールチップは対象外だが、重要な情報を `title` だけで伝えない。

- 構築: CSS の `:hover` に `:focus-within` を並べる。きっかけの要素と表示する内容の間に、ポインターが通る隙間を空けない。Esc で閉じる処理を加える。
- レビュー: Tab で表示できるか、表示した内容の上にポインターを移しても消えないか、Esc で閉じられるかを確かめる。
