# 操作部品の境界と状態は、隣の色と 3:1 以上の差を付ける

- 強さ: 必須
- 対象: 入力欄の枠線、境界線で形を示すボタン、チェックボックスの選択状態、情報を伝えるアイコンやグラフの線。
- WCAG: 1.4.11 AA（2.1 で追加）

操作部品を見分けるために必要な線や形、選択・オンなどの状態を示す色は、隣の色と 3:1 以上のコントラスト比にする。

理由: 薄い灰色の枠線だけの入力欄は、どこに入力欄があるかが分からない。選択状態の色が薄いと、選ばれているかどうかが見分けられない。

例外・代替: 無効の操作部品と、ブラウザの既定の見た目を変えていない操作部品は対象外。背景の色だけで形を示すボタンは、ボタンの背景と周りの背景の差で確かめる。

- 構築: 入力欄の枠線の色は、背景との比を確かめて決める。
- レビュー: 入力欄の枠線、チェックボックス、トグルの状態の色を確かめる。
