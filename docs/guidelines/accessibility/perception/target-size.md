# 操作対象は 24px 四方以上にするか、十分に離す

- 強さ: 必須
- 対象: ポインターやタッチで操作するボタン、リンク、入力部品。
- WCAG: 2.5.8 AA（2.2 で追加）

操作対象の大きさを 24 × 24 CSS ピクセル以上にする。小さくする場合は、各操作対象を中心とした直径 24px の円が、他の操作対象やその円と重ならないように離す。

理由: 小さな操作対象が近くに並ぶと、指や手の震えがある利用者が隣の操作対象を押してしまう。

例外・代替: 文章の中のリンク、同じ機能を持つ別の大きな操作対象が同じページにある場合、ブラウザの既定の大きさを変えていない場合は対象外。

- 構築: アイコンを小さく見せたい場合も、`padding` などで押せる範囲を広げる。
- レビュー: アイコンだけのボタンや、近くに並んだリンクの押せる範囲の大きさを、開発者ツールで確かめる。
