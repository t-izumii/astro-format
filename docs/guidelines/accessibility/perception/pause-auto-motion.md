# 自動で動く内容には、止める手段を付ける

- 強さ: 必須
- 対象: 自動で切り替わるスライド、背景の動画、流れる文字、自動で更新される情報など、自動で始まり、他の内容と並んで表示されるもの。
- WCAG: 2.2.2 A

自動で動く時間が5秒を超える場合は、一時停止・停止・非表示のいずれかのボタンを付ける。自動で更新される情報は、止めるか、更新の頻度を変えられるようにする。

理由: 視界の端で動き続ける内容は、注意の障害がある利用者が他の内容に集中するのを妨げる。読み終わる前に切り替わるスライドは、読む速さが遅い利用者に読めない。

例外・代替: 読み込み中の表示のように、動きがその機能に欠かせない場合は対象外。

- 構築: 停止のボタンは、動く内容の近くの見つけやすい場所に置き、キーボードで操作できるようにする。
- レビュー: 自動で動く内容を探し、5秒を超えて動くものに止める手段があるかを確かめる。
