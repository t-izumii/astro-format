# 色だけで情報を伝えない

- 強さ: 必須
- 対象: エラー、必須、状態、グラフ、本文中のリンクなど、色の違いで意味を伝える箇所。
- WCAG: 1.4.1 A

色の違いに加えて、文字、アイコン、模様、下線などの手がかりを付ける。本文中のリンクには下線を付ける。下線を付けない場合は、周りの文字と 3:1 以上のコントラスト比の色にする。

理由: 色の区別が難しい利用者や、白黒で印刷した場合には、色の違いだけでは意味が伝わらない。

例外・代替: ナビゲーションのように、置かれた場所からリンクだと分かる場合は、下線がなくてもよい。

- 構築: エラーは赤い色だけでなく、エラーの文とアイコンで示す。グラフは系列ごとに線の形や直接のラベルを付ける。
- レビュー: 画面を白黒にした状態で、情報や状態の違いが分かるかを確かめる。
