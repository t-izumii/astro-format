# 1秒間に3回を超えて点滅させない

- 強さ: 必須
- 対象: 点滅や明滅を含むアニメーション、動画。
- WCAG: 2.3.1 A

画面の一部でも、1秒間に3回を超えて明るさが大きく変わる点滅をさせない。

理由: 速い点滅は、光過敏性発作を起こすことがある。発作は一瞬の表示でも起きうるので、止める手段があっても防げない。

例外・代替: 点滅する範囲がごく小さい場合は、基準の閾値を下回ることがあるが、判断が難しいので点滅そのものを避ける。

- 構築: 強調のための点滅は使わず、色や形の変化で示す。
- レビュー: 点滅するアニメーションや動画がある場合は、1秒あたりの点滅の回数を確かめる。
