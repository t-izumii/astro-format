# 文字と背景のコントラスト比を確保する

- 強さ: 必須
- 対象: 文字と、文字を含む画像。
- WCAG: 1.4.3 AA

文字と背景のコントラスト比を 4.5:1 以上にする。大きな文字（目安として 24px 以上、太字なら約 18.5px 以上）は 3:1 以上でよい。写真や模様の上に文字を置く場合は、文字の下で最も明るい部分（白い文字なら）または最も暗い部分を基準に確かめ、足りなければ背景に半透明の色を重ねる。

理由: コントラストが低い文字は、ロービジョンの利用者や、屋外で画面を見る利用者が読めない。

例外・代替: ロゴやブランド名の文字、無効になっている操作部品の文字、装飾だけの文字は対象外。

- 構築: 色はトークンの組み合わせで決め、新しい組み合わせを使うときはコントラスト比を確かめる。
- レビュー: 開発者ツールなどで、文字の色と背景の色のコントラスト比を確かめる。背景が画像の箇所は、画像を差し替えたときも足りるかを確認する。
