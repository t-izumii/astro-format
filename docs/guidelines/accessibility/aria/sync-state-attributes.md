# 状態の属性を実際の状態と同期させる

- 強さ: 必須
- 対象: 開閉、押下、現在地、選択などの状態を持つ操作要素。
- WCAG: 4.1.2 A

状態は、次の属性で伝える。見た目を切り替える処理と同じ場所で属性を更新し、初期値だけ書いて更新しない状態をなくす。

| 状態 | 属性 | 付ける要素 |
|---|---|---|
| 開いている・閉じている | `aria-expanded` | 開閉のきっかけになるボタン（開く内容の側ではない） |
| 押されている（オン・オフの切り替え） | `aria-pressed` | 切り替えボタン |
| 現在のページ・現在の手順 | `aria-current` | ナビゲーションやパンくずの該当リンク |
| 選ばれている | `aria-selected` | タブ、選択肢 |

理由: 見た目だけ切り替わって属性が古いままだと、支援技術の利用者には「閉じている」と伝わったまま内容が開いている、といった食い違いが起きる。

例外・代替: ネイティブの要素が状態を持つ場合（`details` の開閉、チェックボックスの選択など）は、属性を重ねて書かない。

- 構築: 状態を変える関数の中で、見た目と属性を一緒に更新する。
- レビュー: 操作の前後で、属性の値が見た目と一致しているかを開発者ツールで確かめる。
