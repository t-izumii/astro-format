# ネイティブ要素で表せるものに ARIA の役割を付けない

- 強さ: 必須
- 対象: `role` 属性を付ける場合。
- WCAG: 4.1.2 A

HTML の要素で表せる役割は、その要素を使う。`div` に `role="button"` を付けるより `button` を使う。`button` に `role="button"`、`nav` に `role="navigation"` のように、要素が元から持つ役割を重ねて書かない。

理由: ARIA の役割は意味を伝えるだけで、キー操作もフォーカスも用意しない。元からある役割を重ねても効果はなく、書き間違えたときに要素本来の意味を上書きしてしまう。

例外・代替: `list-style: none` で記号を消したリストは、一部のブラウザでリストとして伝わらなくなるため、`ul` に `role="list"` を付けてよい。

- 構築: `role` を書く前に、同じ役割の HTML 要素がないかを確認する。
- レビュー: `role` を検索し、ネイティブ要素で置き換えられるものと、元の役割と重なっているものがないかを確認する。
