# フォーカスを移さずに変化を伝えるときは、ライブリージョンを先に置いておく

- 強さ: 必須
- 対象: 送信の完了、カートへの追加、検索結果の件数など、フォーカスを動かさずに結果を知らせる場合。
- WCAG: 4.1.3 AA（2.1 で追加）

結果を表示する領域に、最初の HTML の時点で `role="status"` を付けておき、結果の文字だけを後から書き換える。`role="alert"` は、すぐに知らせる必要があるエラーや警告だけに使う。

理由: 支援技術は、すでにある領域の中身が変わったときに読み上げる。領域を変化と同時に追加すると、読み上げられないことがある。`role="alert"` は読み上げ中の内容を中断するため、多用すると利用者の操作を妨げる。

例外・代替: 結果を示す場所へフォーカスを移す場合は、ライブリージョンは不要。

- 構築: 入力のたびに読み上げが起きないよう、更新の回数を絞る。
- レビュー: 領域が最初の HTML にあるか、`role="alert"` が緊急でない通知に使われていないかを確認する。

## サンプル: カートへの追加を知らせる

```html
<!-- 最初から空の領域を置いておく -->
<p role="status" class="cart-message"></p>
```

```js
cartMessage.textContent = 'カートに追加しました';
```
