# 操作要素には、見えている文字を含む名前を付ける

- 強さ: 必須
- 対象: ボタン、リンク、入力欄などの操作要素。
- WCAG: 4.1.2 A、2.5.3 A（2.1 で追加）

アイコンだけのボタンには、`aria-label` か、画面に表示しない文字で名前を付ける。見えている文字がある要素に `aria-label` で名前を付ける場合は、見えている文字を名前に含め、できれば先頭に置く。`title` 属性だけで名前を付けない。

理由: 名前のない操作要素は、スクリーンリーダーで「ボタン」としか読まれない。見えている文字と名前が違うと、音声入力の利用者が画面の文字を読み上げても操作できない。

例外・代替: 名前を補いたいだけなら、`aria-label` で置き換えず、見えている文字の後ろに画面に表示しない文字を足す。

- 構築: アイコンの `svg` には `aria-hidden="true"` を付け、名前はボタンの側に付ける。
- レビュー: 操作要素の名前を開発者ツールのアクセシビリティ表示で確認し、空のものと、見えている文字を含まないものがないかを確かめる。

## サンプル: 補足を足すときは見えている文字を残す

```html
<!-- 問題例: 見えている「詳しく見る」が名前に含まれない -->
<a href="/items/1/" aria-label="商品Aの詳細ページ">詳しく見る</a>

<!-- 改善例: 見えている文字を先頭に残し、補足を足す -->
<a href="/items/1/">詳しく見る<span class="visually-hidden">（商品A）</span></a>

<!-- アイコンだけのボタン -->
<button type="button" aria-label="閉じる">
  <svg aria-hidden="true">…</svg>
</button>
```
