# div や span に aria-label を付けない

- 強さ: 必須
- 対象: 役割を持たない `div`・`span` 要素。
- WCAG: 4.1.2 A

`div` と `span` に `aria-label` や `aria-labelledby` を付けない。領域に名前を付けたいときは、`section` や `nav` のように名前を付けられる要素を使うか、見出しを置く。

理由: 役割を持たない要素への名前付けは仕様で禁止されており、支援技術によっては読み上げられない。読み上げられることを前提にした情報が、利用者に届かない。

例外・代替: なし。

- 構築: 説明を足したい内容は、見える文字か、画面に表示しない文字で書く。
- レビュー: `aria-label` と `aria-labelledby` を検索し、付いている要素が名前を付けられるものかを確認する。
