# 役割を付けたら、その役割に必要なキー操作と状態をすべて実装する

- 強さ: 必須
- 対象: `menu`、`tablist`、`listbox`、`grid`、`combobox` など、操作方法が決まっている役割を付ける場合。
- WCAG: 2.1.1 A、4.1.2 A

これらの役割は、矢印キーでの移動など決まった操作を前提にしている。役割を付けるなら、WAI-ARIA Authoring Practices の該当パターンが求めるキー操作と状態をすべて実装する。実装しないなら、その役割を付けない。

理由: 役割を付けると、スクリーンリーダーはその役割に合った操作方法を案内する。実装がそれに応えないと、利用者は案内どおりに操作しても動かない部品に取り残される。

例外・代替: サイトのナビゲーションのように決まった操作がいらない場面では、役割を付けずにボタンとリンクで作る。

- 構築: 役割を付ける前に、Authoring Practices のパターンを読み、キー操作の一覧をすべて実装できるかを判断する。
- レビュー: 役割ごとに、案内されるキー操作が実際に動くかを確かめる。
